# Learning Content Studio workshops

Hands-on technical workshops assembled from Microsoft Learn labs by Learning Content Studio.

**Live site:** https://ivorb.github.io/workshops/

Each workshop is a [just-the-docs](https://just-the-docs.com/) collection under its own `_<slug>/` directory, declared in `_config.yml`. `workshops.json` is the source of truth for the landing page — it is read, updated, and rewritten on every publish, so adding a workshop never disturbs the others.
