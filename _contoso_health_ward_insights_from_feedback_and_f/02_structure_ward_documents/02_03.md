# Task 03 - Build multimodal analyzers for images, audio, and video

## Introduction

Ward operations data does not exist only in PDFs. Contoso Health also needs to capture information from presentation images, voicemail-style recordings, and meeting videos so that Maya Patel, Samir Ahmed, and Dr. Elena Ruiz can work with a fuller operational picture. In this task, you build additional analyzers for those content types.

## Description

You create three more custom Azure Content Understanding projects in Content Understanding Studio. For each project, you define a schema, test it on the initial file, build an analyzer, and then validate it on a second sample file.

## Success Criteria

- You create and test the `slideanalyzer` analyzer for image content.
- You create and test the `voicemailanalyzer` analyzer for audio content.
- You create and test the `meetinganalyzer` analyzer for video content.
- You review extracted fields and JSON outputs for each analyzer.

## Key Tasks

### 01: Create and test the image analyzer

You begin with image content to simulate extracting structured data from a ward presentation slide or operational dashboard screenshot.

1. In **Content Understanding Studio**, go to the **Project list** tab.

1. Select **Create**, and then select **Extract content and fields with a custom schema**.

1. Create a project with the following settings:

    | Setting | Value |
    |---|---|
    | **Project name** | `Slide analysis` |
    | **Description** | `Extract data from an image of a slide` |

1. In **Advanced settings**, verify that the settings are the same as the previous project and continue using `contosohealth-ai`, `contosohealthsa`, and `contosohealthdocs`.

1. Wait for the project to be created.

1. Upload the `slide-1.jpg` file from the folder where you extracted the content files.

1. Select the **Image analysis** template, and then select **Save**.

1. Use **+ Add new field** to add the following fields, selecting **Save changes** (**✓**) for each field:

    | Field name | Field description | Value type | Method |
    |---|---|---|---|
    | `Title` | `Slide title` | String | Generate |
    | `Summary` | `Summary of the slide` | String | Generate |
    | `Charts` | `Number of charts on the slide` | Integer | Generate |

1. Use **+ Add new field** to add a new field named `QuarterlyRevenue` with the description `Revenue per quarter` and the value type **List of objects**.

1. Select the table icon next to the value type dropdown, and then add the following subfields:

    | Field name | Field description | Value type | Method |
    |---|---|---|---|
    | `Quarter` | `Which quarter?` | String | Generate |
    | `Revenue` | `Revenue for the quarter` | Number | Generate |

1. Select **Back** to return to the top level of the schema.

1. Use **+ Add new field** to add a field named `ProductCategories` with the description `Product categories` and the value type **List of objects**.

1. Select the table icon next to the value type, and then add the following subfields:

    | Field name | Field description | Value type | Method |
    |---|---|---|---|
    | `ProductCategory` | `Product category name` | String | Generate |
    | `RevenuePercentage` | `Percentage of revenue` | Number | Generate |

1. Select **Back** to return to the top level of the schema, review the full schema, and then select **Save**.

1. Select the **Test** tab, select **Run analysis**, and wait for analysis to complete.

1. Review the results in the **Fields** pane, expanding `QuarterlyRevenue` and `ProductCategories` to review the subfield values.

1. Select **Build analyzer** and build a new analyzer with the following properties:

    | Setting | Value |
    |---|---|
    | **Name** | `slideanalyzer` |
    | **Description** | `Slide image analyzer` |

1. When the analyzer is built, select **Jump to analyzer list**, and then select the `slideanalyzer` link.

1. On the **Test** tab, use **+ Upload test files** to upload `slide-2.jpg`.

1. Run the analysis and review the extracted fields.

> **Note**: `slide-2.jpg` doesn't include a breakdown by product category, so the product category revenue data is not found.

1. Review the **Results** pane to see the JSON response, and then close the `slideanalyzer` page.

### 02: Create and test the audio analyzer

Next, you analyze audio content to simulate extracting structured information from a care coordination voicemail or handoff recording.

1. In the **Project list** tab, select **Create**, and then select **Extract content and fields with a custom schema**.

1. Create a project with the following settings:

    | Setting | Value |
    |---|---|
    | **Project name** | `Voicemail analysis` |
    | **Description** | `Extract data from a voicemail recording` |

1. In **Advanced settings**, verify that the settings are the same as the previous project.

1. Wait for the project to be created.

1. Upload the `call-1.mp3` file from the folder where you extracted the content files.

1. Select the **Audio analysis** template, and then select **Save**.

1. In the **Content** pane on the right, select **Get transcription preview** to view the transcription.

1. Use **+ Add new field** to add the following fields, selecting **Save** (**✓**) for each field:

    | Field name | Field description | Value type | Method |
    |---|---|---|---|
    | `Caller` | `Person who left the message` | String | Generate |
    | `Summary` | `Summary of the message` | String | Generate |
    | `Actions` | `Requested actions` | String | Generate |
    | `CallbackNumber` | `Telephone number to return the call` | String | Generate |
    | `AlternativeContacts` | `Alternative contact details` | List of Strings | Generate |

1. Select **Run analysis** and wait for analysis to complete.

> **Note**: Audio analysis can take some time to complete.

1. Review the analysis results and inspect the identified fields in the **Fields** pane, including the expanded `AlternativeContacts` values.

1. Select **Build analyzer** and build a new analyzer with the following properties:

    | Setting | Value |
    |---|---|
    | **Name** | `voicemailanalyzer` |
    | **Description** | `Voicemail audio analyzer` |

1. When the analyzer is built, select **Jump to analyzer list**, and then select the `voicemailanalyzer` link.

1. On the **Test** tab, use **+ Upload test files** to upload `call-2.mp3`.

1. Run the analysis to extract field data from the audio file.

1. Review the **Fields** pane and verify that the analyzer extracted the expected values.

1. Review the **Results** pane to see the JSON response, and then close the `voicemailanalyzer` page.

### 03: Create and test the video analyzer

Finally, you analyze video content to simulate extracting operational information from a ward leadership review or clinical operations meeting recording.

1. In Content Understanding Studio, select **Create project** on the home page, or return to the home page first if needed.

1. Select **Extract content and fields with a custom schema**.

1. Create a project with the following settings:

    | Setting | Value |
    |---|---|
    | **Project name** | `Conference call video analysis` |
    | **Description** | `Extract data from a video conference recording` |

1. Wait for the project to be created.

1. Upload the `meeting-1.mp4` file from the folder where you extracted the content files.

1. Select the **Video analysis** template, and then select **Create**.

1. In the **Content** pane on the right, select **Get transcription preview** to see a transcription of the meeting.

1. Use **+ Add new field** to add the following fields, selecting **Save** (**✓**) for each field:

    | Field name | Field description | Value type | Method |
    |---|---|---|---|
    | `Summary` | `Summary of the discussion` | String | Generate |
    | `Participants` | `Count of meeting participants` | Integer | Generate |
    | `ParticipantNames` | `Names of meeting participants` | List of Strings | Generate |
    | `SharedSlides` | `Descriptions of any PowerPoint slides presented` | List of Strings | Generate |
    | `AssignedActions` | `Tasks assigned to participants` | List of Objects | Generate |

1. For the `AssignedActions` field, create the following subfields:

    | Field name | Field description | Value type | Method |
    |---|---|---|---|
    | `Task` | `Description of the task` | String | Generate |
    | `AssignedTo` | `Who the task is assigned to` | String | Generate |

1. Select **Back** to return to the top level of the schema.

1. Save the schema.

1. Select **Run analysis** and wait for analysis to complete.

> **Note**: Video analysis can take some time to complete.

1. When the analysis completes, review the extracted data in the **Fields** pane.

1. Select **Build analyzer** and build a new analyzer with the following properties:

    | Setting | Value |
    |---|---|
    | **Name** | `meetinganalyzer` |
    | **Description** | `Meeting video analyzer` |

1. Wait for the analyzer to be ready, using **Refresh** if needed.

1. Select **Jump to analyzer list**, and then select the `meetinganalyzer` link.

1. On the **Test** tab, use **+ Upload test files** to upload `meeting-2.mp4`.

1. Run the analysis to extract field data from the video file.

1. Review the **Fields** pane and the extracted fields for each shot in the conference call video.

1. Review the **Results** pane to see the JSON response that the analyzer would return to a client application.

1. Close the `meetinganalyzer` page.
