# Task 04 - Clean up the workshop resources

## Introduction

Azure Content Understanding and supporting resources can incur costs while they remain deployed. After you finish exploring the multimodal extraction workflow for Contoso Health, remove the workshop resources if you no longer need them.

## Description

In this task, you delete the shared workshop resource group so the Foundry, storage, and related resources are removed together.

## Success Criteria

- You identify the workshop resource group `rg-contosohealth-workshop`.
- You start deletion of the resource group after confirming that you no longer need the workshop resources.

## Key Tasks

### 01: Delete the workshop resource group

If you've finished working with Azure Content Understanding for this workshop, delete the resources you created to avoid incurring unnecessary Azure costs.

1. Open the [Azure portal](https://portal.azure.com) at `https://portal.azure.com`.

1. Open the `rg-contosohealth-workshop` resource group.

1. Review the resources in the group, including `contosohealth-ai`, `contosohealthsa`, `contosohealthopenai`, and any related workshop assets, to confirm that you no longer need them.

1. Select **Delete resource group**.

1. Enter `rg-contosohealth-workshop` to confirm the deletion.

1. Select **Delete**.

> **Important**: Deleting the resource group removes all shared workshop resources, including the Microsoft Foundry project dependencies and stored content in `contosohealthdocs`.
