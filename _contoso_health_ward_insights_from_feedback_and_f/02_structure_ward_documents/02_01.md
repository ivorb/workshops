# Task 01 - Prepare Content Understanding for the Contoso Health workshop

## Introduction

Before you can extract structured fields from ward documents, you need to confirm that the shared workshop project and content environment are ready. In this task, you use the existing Contoso Health Foundry project, download the sample multimodal files, and connect Content Understanding Studio to the shared workshop resources.

## Description

You sign in to Microsoft Foundry, verify that you can use the shared `contosohealthproj` project, download the sample files for this exercise, and connect Content Understanding Studio to `contosohealth-ai`. You also make sure the shared storage resources are available for the custom analyzer projects you build later.

## Success Criteria

- You open the **Foundry (new)** experience in the Microsoft Foundry portal.
- You verify that the shared `contosohealthproj` project is available.
- You download and extract the sample content files locally.
- You connect Content Understanding Studio to the `contosohealth-ai` resource.
- You confirm that the shared storage account and blob container can be used for custom analyzer projects.

## Key Tasks

### 01: Open the shared Foundry project

The features you use in this exercise require a Microsoft Foundry resource and project. In this workshop, those shared resources already exist for Contoso Health.

1. Open the [Microsoft Foundry portal](https://ai.azure.com) at `https://ai.azure.com` and sign in using your Azure credentials. Close any tips or quick start panes that open the first time you sign in.

1. Make sure the **New Foundry** toggle is on so that you're using **Foundry (new)**.

1. Select the project name in the upper-left corner and verify that the shared project `contosohealthproj` is available and selected.

1. Confirm that the project is associated with the workshop environment that uses the shared resource group `rg-contosohealth-workshop`.

> **Note**: Azure Content Understanding is available in selected regions. If a feature isn't available in your environment, verify that the shared workshop resources were created in a supported region.

### 02: Download the workshop content files

The content you analyze in this exercise is stored in a `.zip` archive. Download it and extract it to a local folder so you can use the sample document, image, audio, and video files during testing.

1. Open a new browser tab and download `content.zip` from `https://github.com/microsoftlearning/mslearn-ai-information-extraction/raw/main/Labfiles/content/content.zip`.

1. Save the file in a local folder on your Windows 11 desktop environment.

1. Extract the downloaded `content.zip` file and review the files it contains.

1. Keep the extracted folder available. You use these files throughout the rest of the exercise.

> **Note**: Although the sample files were originally designed as generic examples, in this workshop you treat them as representative Contoso Health operational content such as scanned ward forms, presentation images, voicemail-style care coordination messages, and meeting recordings.

### 03: Connect Content Understanding Studio to the shared resource

To build custom analyzers, you use **Content Understanding Studio**, which is a separate web-based tool for creating schemas and testing multimodal extraction.

1. Open [Content Understanding Studio](https://contentunderstanding.ai.azure.com) at `https://contentunderstanding.ai.azure.com` in a new browser tab.

1. If you're prompted, sign in with the same Azure credentials you used for the Foundry portal.

1. On the **Settings** page, or if you're redirected to set up your resource, select **+ Add resource**.

1. Select the shared Foundry resource `contosohealth-ai`, and then select **Next** > **Save**.

1. Make sure the **Enable autodeployment for required models if no defaults are available** checkbox is selected.

> **Tip**: This setting ensures your resource is set up with the required `GPT-4.1`, `GPT-4.1-mini`, and `text-embedding-3-large` models that custom analyzers need.

1. After the resource is connected, select **Content Understanding** in the top navigation to go to the home page.

1. Verify that you can use the shared storage account `contosohealthsa` and the blob container `contosohealthdocs` when you create custom projects later in the exercise.

> **Tip**: If access to storage isn't available immediately, wait a minute and try again. Permissions for newly configured resources can take a few minutes to propagate.
