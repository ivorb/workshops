# Task 02 - Connect Content Understanding Studio to the workshop resources

## Introduction

Prebuilt analyzers help you inspect raw content, but Contoso Health needs field-level extraction that maps to operational workflows. In this task, you connect Content Understanding Studio to the shared workshop resources so you can create custom analyzers without provisioning a separate environment.

## Description

You open Content Understanding Studio, connect the shared Foundry resource, and verify access to the shared storage account `stcontosohealthworkshop`. This ensures your custom projects can use the same controlled resource set for storing and analyzing uploaded content.

## Success Criteria

- Content Understanding Studio is connected to the Foundry resource behind `ai-contosohealth-foundry`.
- The connection uses the shared workshop environment in `rg-contosohealth-workshop`.
- You can proceed to create custom projects that use `stcontosohealthworkshop`.

## Key Tasks

### 01: Open Content Understanding Studio

1. Open a new browser tab and go to [Content Understanding Studio](https://contentunderstanding.ai.azure.com) at `https://contentunderstanding.ai.azure.com`.

1. If prompted, sign in with the same Azure credentials that you used for the Foundry portal.

1. On the **Settings** page, or if you are redirected to set up your resource, select **+ Add resource**.

### 02: Connect the Contoso Health Foundry resource

1. Select the Foundry resource associated with `ai-contosohealth-foundry`, and then select **Next** > **Save**.

> **Tip**: Make sure that the **Enable autodeployment for required models if no defaults are available** checkbox is selected. This ensures your resource is set up with the required `GPT-4.1`, `GPT-4.1-mini`, and `text-embedding-3-large` models that custom analyzers need.

1. Wait for the resource connection to complete.

1. After your resource is connected, select **Content Understanding** in the top navigation to go to the home page.

1. Verify that Content Understanding Studio is now using the shared Contoso Health workshop environment.

### 03: Confirm storage availability

1. Make sure the shared storage account `stcontosohealthworkshop` exists in `rg-contosohealth-workshop` and is available for project setup.

1. If you need to verify this, open the [Azure portal](https://portal.azure.com) at `https://portal.azure.com`, sign in, and review the resources in `rg-contosohealth-workshop`.

1. Confirm that `stcontosohealthworkshop` is present and can be selected when you create a custom project.

1. Return to Content Understanding Studio and leave it open for the next task.
