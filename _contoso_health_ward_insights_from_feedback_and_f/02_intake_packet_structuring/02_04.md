# Task 04 - Build a custom analyzer for image-based intake content

## Introduction

Not all intake-related content arrives as standard forms. Contoso Health also receives images and visual artifacts that need structured interpretation so operations teams can route and review them consistently. In this task, you create an image analyzer that extracts structured fields from image-based content.

## Description

You create a second custom project, upload a sample image, define a schema manually, test the schema, and then build the `slideanalyzer` analyzer. You validate the analyzer on a second image and review both the field output and the JSON payload that an application could consume.

## Success Criteria

- A custom image project is created with the same workshop resource settings.
- The schema includes all required generated fields and nested object lists.
- The analyzer `slideanalyzer` is built successfully.
- Testing confirms the analyzer extracts structured values from the second sample image.

## Key Tasks

### 01: Create the custom image project

1. In the **Project list** tab, select **Create**.

1. Select **Extract content and fields with a custom schema**, and then create a project with the following settings:

    - **Project name**: `Slide analysis`
    - **Description**: `Extract data from an image of a slide`
    - **Advanced settings**: Verify the settings are the same as the last project, including the resource associated with `ai-contosohealth-foundry` and the storage account `stcontosohealthworkshop`

1. Wait for the project to be created.

1. Verify that the project is ready for image upload.

### 02: Define the image analysis schema

1. Upload the `slide-1.jpg` file from the folder where you extracted the sample content files.

1. Select the **Image analysis** template, and then select **Save**.

1. Use **+ Add new field** to add the following fields, selecting **Save changes** (**&#10003;**) for each one:

    | Field name | Field description | Value type | Method |
    |--|--|--|--|
    | `Title` | `Slide title` | String | Generate |
    | `Summary` | `Summary of the slide` | String | Generate |
    | `Charts` | `Number of charts on the slide` | Integer | Generate |

1. Use **+ Add new field** to add a new field named `QuarterlyRevenue` with the description `Revenue per quarter` and the value type **List of objects**.

1. Select the table icon next to the value type dropdown.

1. In the page for the table subfields, add the following subfields:

    | Field name | Field description | Value type | Method |
    |--|--|--|--|
    | `Quarter` | `Which quarter?` | String | Generate |
    | `Revenue` | `Revenue for the quarter` | Number | Generate |

1. Select **Back** to return to the top level of your schema.

1. Use **+ Add new field** to add a new field named `ProductCategories` with the description `Product categories` and the value type **List of objects**.

1. Select the table icon next to the value type to open the page for the table subfields.

1. Add the following subfields:

    | Field name | Field description | Value type | Method |
    |--|--|--|--|
    | `ProductCategory` | `Product category name` | String | Generate |
    | `RevenuePercentage` | `Percentage of revenue` | Number | Generate |

1. Select **Back** to return to the top level of your schema.

1. Verify that the schema looks like this, and then select **Save**.

![Screenshot of the image analyzer schema in Content Understanding Studio showing fields for Title, Summary, Charts, QuarterlyRevenue, and ProductCategories.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-information-extraction/main/Instructions/Exercises/media/slide-schema.png)

### 03: Test the schema and build the image analyzer

1. Select the **Test** tab.

1. Select **Run analysis**, and then wait for the analysis to complete.

1. Review the analysis results, which should look similar to this:

![Screenshot of image analysis test results in Content Understanding Studio showing extracted fields from the slide including revenue data and product categories.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-information-extraction/main/Instructions/Exercises/media/slide-analysis.png)

1. In the **Fields** pane, review the extracted values.

1. Expand the **QuarterlyRevenue** and **ProductCategories** fields to inspect the subfield values.

1. Select **Build analyzer** at the top of the page.

1. Build a new analyzer with the following properties, typed exactly as shown:

    - **Name**: `slideanalyzer`
    - **Description**: `Slide image analyzer`

1. When the analyzer has been built, select **Jump to analyzer list**.

1. In the analyzer list, select the `slideanalyzer` link.

### 04: Test the built image analyzer

1. On the `slideanalyzer` page, select the **Test** tab.

1. Use **+ Upload test files** to upload `slide-2.jpg` from the folder where you extracted the sample content files.

1. Run the analysis to extract field data from the image.

1. In the **Fields** pane, verify that the analyzer extracted the correct fields from the slide image.

> **Note**: Slide 2 does not include a breakdown by product category, so the product category revenue data is not found.

1. In the **Results** pane, review the JSON response that the analyzer would return to a client application.

1. Close the `slideanalyzer` page.

1. Verify that you now have working document and image analyzers that demonstrate the Contoso Health intake packet structuring pattern.
