# Task 01 - Prepare the Contoso Health multimodal workspace

## Introduction

Contoso Health already has a text-based feedback pipeline, but intake operations also rely on scanned forms and image-based content that staff must review manually. In this task, you make sure the shared multimodal workspace is ready so you can test document extraction in the same environment used across the workshop.

## Description

You open the Foundry project environment, download the sample content archive, and confirm that the files needed for this exercise are available locally. You then explore the prebuilt Azure Content Understanding analyzers in the Foundry portal to understand how raw document structure can be extracted before you build custom healthcare-oriented schemas.

## Success Criteria

- You can sign in to the Foundry portal and access the project tied to `ai-contosohealth-foundry`.
- You have downloaded and extracted the sample content archive to a local folder.
- You have run the prebuilt **Azure Content Understanding - Layout** analyzer against the sample PDF.
- You understand the difference between the prebuilt **Read** and **Layout** analyzers.

## Key Tasks

### 01: Open the shared Foundry project context

1. Open Microsoft Edge and go to the [Microsoft Foundry portal](https://ai.azure.com) at `https://ai.azure.com`, and then sign in with your Azure credentials.

1. Close any tips or quick start panes that open the first time you sign in.

1. Make sure the **New Foundry** toggle is on so that you are using **Foundry (new)**.

1. If you are prompted to create a new project automatically, do not create a separate workshop environment unless you must. Instead, open or select the project associated with `ai-contosohealth-foundry` in `rg-contosohealth-workshop`.

1. If you are not automatically in the correct project, select the project name in the upper-left corner and switch to the project backed by the shared workshop resources.

1. Verify that you can access the project workspace and that it is associated with the Contoso Health workshop environment.

### 02: Download the sample intake content

1. Open a new browser tab.

1. Download `content.zip` from `https://github.com/microsoftlearning/mslearn-ai-information-extraction/raw/main/Labfiles/content/content.zip` and save it in a local folder.

1. Extract the downloaded `content.zip` file.

1. Review the extracted files so you know what content is available for analysis in this exercise.

> **Note**: The sample content includes multiple content types. In this exercise, you focus on document and image-based extraction to support Contoso Health intake packet structuring.

### 03: Try the prebuilt document analyzer

1. Return to the [Microsoft Foundry portal](https://ai.azure.com) and confirm that the **New Foundry** toggle is still on.

1. Select **Build** in the upper-right menu, and then select **Deployments** in the left pane.

1. Select the **AI Services** tab to view the prebuilt models provided by Foundry Tools.

1. Find and select **Azure Content Understanding - Layout**.

1. In the playground, use the option to upload your own data and upload the `invoice-1234.pdf` file from the folder where you extracted the content files. For this workshop, treat this sample document as a stand-in for a scanned intake packet page that Contoso Health wants to structure.

![Image of an invoice number 1234.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-information-extraction/main/Instructions/Exercises/media/invoice-1234.png)

1. Run the analyzer and wait for the analysis to complete.

1. Review the results in both the formatted view and the raw JSON view.

1. Notice that the **Layout** analyzer extracts text, tables, and structural elements such as paragraphs and sections from the document.

> **Note**: The prebuilt **Read** and **Layout** analyzers extract content from documents without requiring a generative AI model. **Read** extracts text elements such as words, paragraphs, formulas, and barcodes, while **Layout** also extracts tables, figures, document structure, hyperlinks, and annotations. These analyzers are useful when you need general-purpose extraction, but they do not extract the specific custom fields that Contoso Health operations teams need.

1. Optionally, go back to the **AI Services** tab and try **Azure Content Understanding - Read** with the same file to compare the results.

1. Verify that **Read** extracts text without the same level of layout analysis.

### 04: Confirm you are ready for custom analyzers

1. Make sure you still have the extracted sample files available locally.

1. Confirm that you can reach both the Foundry portal and the project backed by `ai-contosohealth-foundry`.

1. Verify that you are ready to continue to Content Understanding Studio, where you will create custom schemas for structured extraction.
