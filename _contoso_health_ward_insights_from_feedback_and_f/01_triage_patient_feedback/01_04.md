# Task 04 - Analyze and protect patient feedback

## Introduction

In this task, you add the core triage capabilities that Contoso Health needs for patient feedback. You detect language, identify entities, and redact PII so the comments can support operational insight while still respecting privacy requirements that matter to Marcus Bell and the broader compliance team.

## Description

You extend the Python application in three small steps. First, you detect the language of each patient comment. Next, you extract entities that might point to wards, people, places, or time references. Finally, you identify and redact PII so the results are safer to use in downstream reporting and in the next exercise.

## Success Criteria

- The application detects and displays the language for each feedback file.
- The application extracts and displays entities from each feedback file.
- The application identifies PII entities and shows a redacted version of the text.
- You can explain how the output supports privacy-aware patient feedback triage at Contoso Health.

## Key Tasks

### 01: Detect the language of patient comments

The first analysis step helps you understand what language each comment uses before you perform downstream processing.

1. In `text-analysis.py`, find the comment `Get language`.

1. Add the following code:

    ```python
    # Get language
    detectedLanguage = ai_client.detect_language(documents=[text])[0]
    print('\nLanguage: {}'.format(detectedLanguage.primary_language.name))
    ```

    This code sends each review document to the service and prints the detected primary language.

1. Save the file with **Ctrl+S**.

1. Run the application again:

    ```text
    python text-analysis.py
    ```

1. Review the output and confirm that a language value is shown for each patient feedback file.

   > **Note**: In this example, each review is analyzed individually, resulting in a separate call to the service for each file. An alternative approach is to create a collection of documents and pass them to the service in a single call. In both approaches, the response consists of a collection of documents, which is why the code uses `[0]` to select the first and only result.

1. Verify that language detection completes successfully for all files.

### 02: Extract entities from patient feedback

Entity recognition helps you identify useful references in the text, such as people, places, organizations, and time-related details that may matter for ward-level insight.

1. In `text-analysis.py`, find the comment `Get entities`.

1. Add the following code:

    ```python
    # Get entities
    entities = ai_client.recognize_entities(documents=[text])[0].entities
    if len(entities) > 0:
         print("\nEntities")
         for entity in entities:
             print('\t{} ({})'.format(entity.text, entity.category))
    ```

    This code calls the entity recognition feature and prints any entities found in each review.

1. Save the file with **Ctrl+S**.

1. Run the application again:

    ```text
    python text-analysis.py
    ```

1. Review the output and note the detected entities.

1. Consider how Olivia Chen could use these results to identify recurring feedback themes or contextual details that affect ward operations.

1. Verify that entity output appears for the review files.

### 03: Identify and redact PII

Because patient comments may contain protected or personally identifiable information, you add a privacy-aware processing step before this data is reused elsewhere.

1. In `text-analysis.py`, find the comment `Get PII`.

1. Add the following code:

    ```python
    # Get PII
    pii_result = ai_client.recognize_pii_entities(documents=[text])[0]
    pii_entities = pii_result.entities
    if len(pii_entities) > 0:
         print("\nPII Entities")
         for pii_entity in pii_entities:
             print('\t{} ({})'.format(pii_entity.text, pii_entity.category)) 
         print("Redacted Text:\n {}".format(pii_result.redacted_text))
    ```

    This code identifies PII entities in each document and prints a redacted version of the text that can be handled more safely in reporting workflows.

1. Save the file with **Ctrl+S**.

1. Run the application again:

    ```text
    python text-analysis.py
    ```

1. Review the output and observe:
   - The PII entities that are identified
   - The redacted text produced for each review

1. If the app fails because the rate limit is exceeded, wait a few seconds and try again.

1. When you finish testing, deactivate the Python environment by running:

    ```bash
    deactivate
    ```

1. Verify that you now have a working patient feedback triage workflow that detects language, extracts entities, and redacts PII.
