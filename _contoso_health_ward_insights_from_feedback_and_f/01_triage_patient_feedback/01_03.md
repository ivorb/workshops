# Task 03 - Connect the application to Azure Language

## Introduction

In this task, you connect the application to Azure Language by using the Python SDK and Microsoft Entra ID. This is the point where the local app becomes part of Contoso Health’s Azure-based analytics workflow.

## Description

You update the starter code to import the required namespaces, create a `TextAnalyticsClient`, sign in to Azure with the Azure CLI, and run the app to confirm the connection works before adding analysis features.

## Success Criteria

- The Python file includes the required Azure SDK imports.
- The application creates a `TextAnalyticsClient` by using `DefaultAzureCredential`.
- You sign in successfully with `az login`.
- The application runs and displays the contents of each patient feedback file without error.

## Key Tasks

### 01: Add the Azure SDK imports

You start by importing the namespaces required to authenticate and connect to Azure Language.

1. In the **Explorer** pane, open `text-analysis.py`.

1. Review the existing code so you can identify where to add the new statements.

1. Find the comment `Import namespaces` and add the following code:

    ```python
    # import namespaces
    from azure.identity import DefaultAzureCredential
    from azure.ai.textanalytics import TextAnalyticsClient
    ```

    This code imports the credential type used for Microsoft Entra ID authentication and the client class used to call Azure Language.

1. Save the file with **Ctrl+S**.

1. Verify that there are no syntax errors shown in the editor.

### 02: Create the Azure Language client

Now you create a client object that uses the endpoint from `.env` and your signed-in Azure identity.

1. In `text-analysis.py`, find the comment `Create client using endpoint`.

1. Add the following code:

    ```Python
    # Create client using endpoint
    credential = DefaultAzureCredential()
    ai_client = TextAnalyticsClient(endpoint=foundry_endpoint, credential=credential)
    ```

    This code creates a credential from your current Azure sign-in context and uses it to initialize the Text Analytics client.

1. Save the file with **Ctrl+S**.

1. Verify that the code indentation matches the surrounding code in the `main` function.

### 03: Sign in to Azure and validate the connection

Before the application can use `DefaultAzureCredential`, you must sign in to Azure in the terminal.

1. In the integrated terminal, run the following command:

    ```powershell
    az login
    ```

    This command signs you in interactively so the application can use your Azure identity.

1. Complete the sign-in process in the browser if prompted.

1. Return to the terminal and confirm the details of the subscription that contains `contosohealthproj` and `rg-contosohealth-workshop`.

   > **Note**: In most scenarios, just using `az login` is sufficient. However, if you have subscriptions in multiple tenants, you may need to specify the tenant by using the `--tenant` parameter.

1. Run the application:

    ```text
    python text-analysis.py
    ```

    At this point, the application creates the Text Analytics client but does not yet call analysis operations.

1. Observe the output. You should see the contents of each review text file in the `reviews` folder displayed without errors.

1. Verify that the application runs successfully and that the connection setup is complete.
