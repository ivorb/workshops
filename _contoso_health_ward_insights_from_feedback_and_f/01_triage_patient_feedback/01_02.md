# Task 02 - Configure the Python application for patient feedback triage

## Introduction

In this task, you prepare the local development environment for the Contoso Health feedback triage app. This matters because Olivia Chen needs a repeatable way to run and update the workflow as patient comments arrive from different wards.

## Description

You configure Python in Visual Studio Code, create or select a virtual environment, install the required packages, and update the application settings so the app can connect to the `contosohealthproj` environment.

## Success Criteria

- The **Python** extension is installed in Visual Studio Code.
- A Python virtual environment is active in the integrated terminal.
- The required dependencies install successfully from `requirements.txt`.
- The `.env` file contains the correct Foundry endpoint format.

## Key Tasks

### 01: Prepare the Python environment

You need a working Python environment before you can connect the application to Azure Language.

1. In Visual Studio Code, open the **Extensions** pane.

1. Install the **Python** extension if it is not already installed.

1. Open the **Command Palette** with **Ctrl+Shift+P** and run the `Python: Select Interpreter` command.

1. Select an existing Python environment if you have one, or create a new **Venv** environment based on your Python 3.13.x installation.

   > **Tip**: If you are prompted to install dependencies, you can install the ones in the `requirements.txt` file in `Labfiles/01-analyze-text/Python/text-analysis`, but it is also fine to do that in the terminal in the next steps.

   > **Tip**: If you prefer to use the terminal, you can create your **Venv** environment by running the following command:

    ```bash
    python -m venv labenv
    ```

    Then activate it by running:

    ```bash
    \labenv\Scripts\activate
    ```

1. In the **Explorer** pane, right-click the `text-analysis` folder and select **Open in Integrated Terminal**.

1. Confirm that the terminal opens in the `text-analysis` folder and that the prompt includes `(.venv)` or the name of your active environment.

1. Verify that the terminal is ready for package installation.

### 02: Install the required packages

The application uses the Azure Language Text Analytics SDK and supporting packages.

1. In the integrated terminal, run the following command:

    ```text
    pip install -r requirements.txt
    ```

    This installs the dependencies needed by the sample application.

1. Wait for the installation to finish.

1. Review any installation messages and confirm that the packages install without errors.

1. Verify that the environment is still active after installation.

### 03: Update the application configuration

The application reads the service endpoint from the `.env` file. You must configure it to point to the Foundry resource associated with `contosohealthproj`.

1. In the **Explorer** pane, open the `.env` file in the `text-analysis` folder.

1. Update the configuration values to include the endpoint for your Foundry project, copying it from the `contosohealthproj` page in the **Microsoft Foundry portal**.

1. Modify the pasted endpoint to remove the `/api/projects/{project_name}` suffix so the endpoint uses this format:

    ```text
    https://{your-foundry-resource-name}.services.ai.azure.com
    ```

    This ensures the SDK connects to the Azure AI service endpoint rather than the project API path.

1. Save the `.env` file with **Ctrl+S**.

1. Verify that the endpoint value ends at `.com` and does not include `/api/projects/contosohealthproj`.
