# Task 01 - Set up the Contoso Health workshop environment

## Introduction

In this task, you prepare the shared workshop environment that Contoso Health uses across both exercises. You create or open the Microsoft Foundry project and get the starter application files that Olivia Chen will use to triage patient feedback for ward reporting.

## Description

You sign in to the Foundry portal, create the shared project for the workshop if needed, and download the Python starter files from GitHub. You then open the application folder in Visual Studio Code so you can configure and run the text analysis workflow.

## Success Criteria

- You can open the **Microsoft Foundry portal** and access the `contosohealthproj` project.
- You note the project endpoint you will use later in the application.
- You clone the sample repository and open the Python app files in Visual Studio Code.
- You can see the `.env`, `requirements.txt`, `text-analysis.py`, and `reviews` files in the application folder.

## Key Tasks

### 01: Open or create the shared Foundry project

Microsoft Foundry uses projects to organize models, resources, data, and other assets used to develop an AI solution. In this workshop, you use the shared project `contosohealthproj` for Contoso Health.

1. Open Microsoft Edge, go to the **Microsoft Foundry portal** at `https://ai.azure.com`, and sign in with your Azure credentials.

1. Close any first-run tips or quick start panes. If needed, use the Foundry logo in the upper-left corner to return to the home page.

1. If it is not already enabled, in the toolbar at the top of the page, enable **New Foundry**.

1. Open the project named `contosohealthproj` if it already exists.

1. If `contosohealthproj` does not exist, create a new project and expand **Advanced options**. Use the following settings:
   - **Project name**: `contosohealthproj`
   - **Foundry resource**: *Use the default name for your resource (usually `contosohealthproj-resource`)*
   - **Subscription**: *Your Azure subscription*
   - **Resource group**: `rg-contosohealth-workshop`
   - **Region**: Select any available region

   > **Note**: Use a recommended Microsoft Foundry region. Model availability may vary by region.

1. Select **Create** and wait for the project to be created.

1. On the home page for `contosohealthproj`, review the displayed connection details and note the project endpoint and OpenAI endpoint.

   > **Tip**: You need the project endpoint later when you configure the application.

1. Verify that the project home page opens successfully and shows the project details for `contosohealthproj`.

### 02: Get the patient feedback application files

The initial application files you need to develop the patient feedback triage workflow are provided in a GitHub repo. You reuse the existing sample structure and retheme it for the Contoso Health scenario.

1. Open Visual Studio Code.

1. Open the command palette with **Ctrl+Shift+P** and run the `Git: Clone` command.

1. Enter the following repository URL:

    ```text
    https://github.com/microsoftlearning/mslearn-ai-language
    ```

    This repository contains the starter Python application and sample review files used in the exercise.

1. Choose a local folder for the clone operation, and then open the cloned repository in Visual Studio Code.

1. If prompted to trust the authors, confirm that you trust the repository.

1. In the **Explorer** pane, navigate to `Labfiles/01-analyze-text/Python/text-analysis`.

1. Review the application files in the folder. You should see:
   - `reviews` folder
   - `.env`
   - `requirements.txt`
   - `text-analysis.py`

1. Verify that the `text-analysis` folder opens correctly and contains all of the expected files.

### 03: Review how this task fits the workshop story

Before you start coding, connect the technical assets to the Contoso Health scenario so the exercise remains grounded in the workshop narrative.

1. Treat the text files in the `reviews` folder as patient feedback comments collected across Contoso Health wards.

1. Treat the analysis results as the first-pass triage output that Olivia Chen will use to prepare privacy-aware insight for Maya Patel, Jordan Kim, and Dr. Elena Ruiz.

1. Keep using the shared workshop resource names throughout the exercise:
   - `rg-contosohealth-workshop`
   - `contosohealth-ai`
   - `contosohealthsa`
   - `contosohealthdocs`
   - `contosohealthopenai`
   - `contosohealthproj`

1. Verify that you are ready to continue with the same project and naming conventions for the rest of the exercise.
