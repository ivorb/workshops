# Task 03 - Connect the application to Azure Language

## Introduction

In this task, you connect the Python application to Azure Language in Foundry Tools. This connection is the foundation for the rest of the workshop because it enables Contoso Health’s analytics team to run text analysis operations against patient feedback data.

## Description

You add the SDK imports, create the `TextAnalyticsClient`, sign in to Azure with the Azure CLI, and run the application to verify that it connects successfully before any analysis logic is added.

## Success Criteria

- You add the required SDK imports to `text-analysis.py`.
- You create a `TextAnalyticsClient` that uses `DefaultAzureCredential`.
- You sign in successfully by using `az login`.
- The application runs and displays the feedback text files without errors.

## Key Tasks

### 01: Add the SDK imports and client code

The starter app already loads configuration values. Now you add the code that creates the client for the Text Analytics API.

1. In the **Explorer** pane, open `text-analysis.py`.

1. Review the existing code. You add code to work with the Azure Language Text Analytics SDK.

   > **Tip**: As you add code to the code file, be sure to maintain the correct indentation.

1. At the top of the code file, under the existing namespace references, find the comment `Import namespaces` and add the following code:

   ```python
   # import namespaces
   from azure.identity import DefaultAzureCredential
   from azure.ai.textanalytics import TextAnalyticsClient
   ```

   This code imports the credential type and client class that the app uses to authenticate and call Azure Language.

1. In the `main` function, find the comment `Create client using endpoint` and add the following code:

   ```python
   # Create client using endpoint
   credential = DefaultAzureCredential()
   ai_client = TextAnalyticsClient(endpoint=foundry_endpoint, credential=credential)
   ```

   This code creates the client by using the endpoint from the `.env` file and Microsoft Entra ID authentication.

1. Save the changes to `text-analysis.py` with **Ctrl+S**.

1. Verify that the file now includes the import statements and the client creation code without syntax errors.

### 02: Sign in to Azure and validate the connection

You now authenticate locally and run the app to confirm that the connection works before you add analysis features.

1. In the integrated terminal, sign in to Azure by running the following command:

   ```powershell
   az login
   ```

   This command authenticates the local development session so `DefaultAzureCredential` can access the Azure resource.

1. If prompted, follow the sign-in instructions. Then complete the sign-in process in the command line, review the subscription details, and confirm that you are using the subscription that contains `contosohealth-ai`.

   > **Note**: In most scenarios, just using `az login` is sufficient. However, if you have subscriptions in multiple tenants, you may need to specify the tenant by using the `--tenant` parameter.

1. Run the application by using the following command:

   ```text
   python text-analysis.py
   ```

   At this stage, the application creates a client successfully but does not yet perform text analysis operations.

1. Observe the output. The code should run without error and display the contents of each review text file in the `reviews` folder.

1. Verify that the app runs successfully and that no authentication or endpoint errors are returned.
