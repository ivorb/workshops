# Task 01 - Create the Contoso Health text analysis workspace

## Introduction

In this task, you set up the Microsoft Foundry project that Contoso Health uses for the workshop solution. This project gives Daniel Cho a workspace for building the ward feedback analysis workflow and provides the endpoint that the Python application will use later.

## Description

You sign in to the Foundry portal, create a project for this exercise, and review the connection details that the application needs. You also download the starter files that contain the sample feedback processing app.

## Success Criteria

- You create a Microsoft Foundry project successfully.
- You can view the project endpoint and OpenAI endpoint on the project home page.
- You clone the lab repository and locate the `text-analysis` application files.

## Key Tasks

### 01: Create a Microsoft Foundry project

Microsoft Foundry uses projects to organize models, resources, data, and other assets used to develop an AI solution.

1. Open Microsoft Edge and go to the [Microsoft Foundry portal](https://ai.azure.com) at `https://ai.azure.com`, and then sign in using your Azure credentials. Close any tips or quick start panes that open the first time you sign in, and if necessary use the Foundry logo at the upper-left to navigate to the home page.

1. If it is not already enabled, on the toolbar at the top of the page, enable the **New Foundry** option. Then, if prompted, create a new project with a unique name; expand the **Advanced options** area and specify the following settings for your project:
   - **Foundry resource**: `contosohealth-ai`
   - **Subscription**: *Your Azure subscription*
   - **Resource group**: `rg-contosohealth-workshop`
   - **Region**: Select any available region

   > **Note**: Use a recommended Microsoft Foundry region. Model availability may vary by region.

1. Select **Create** and wait for your project to be created.

1. On the home page for your project, note that the API key, project endpoint, and OpenAI endpoint are displayed.

   > **Tip**: You need the project endpoint later.

1. Verify that the project opens successfully and that you can see the connection details on the project home page.

### 02: Get the application files from GitHub

The initial application files you need are provided in a GitHub repo. These files contain the Python app that you will adapt for Contoso Health’s patient feedback analysis workflow.

1. Open Visual Studio Code.

1. Open the command palette with **Ctrl+Shift+P** and run the `Git: Clone` command to clone the `https://github.com/microsoftlearning/mslearn-ai-language` repo to a local folder. Then open the cloned folder.

   You may be prompted to confirm that you trust the authors.

1. In the **Explorer** pane, navigate to `Labfiles/01-analyze-text/Python/text-analysis`.

1. Review the application files in the folder:
   - `reviews` folder
   - `.env`
   - `requirements.txt`
   - `text-analysis.py`

1. Verify that you can see the `text-analysis` folder and its files in Visual Studio Code.
