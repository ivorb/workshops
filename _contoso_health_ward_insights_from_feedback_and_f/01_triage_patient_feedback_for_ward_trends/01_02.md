# Task 02 - Configure the patient feedback analysis application

## Introduction

In this task, you prepare the Python environment for the Contoso Health analytics workflow. This setup ensures that you can run the application locally and connect it securely to the Foundry resource that supports the ward feedback scenario.

## Description

You install or confirm the Python tooling, create a virtual environment, install the required packages, and configure the application endpoint. This gives the starter application the connection information it needs before you begin adding text analysis code.

## Success Criteria

- You create or select a Python virtual environment in Visual Studio Code.
- You install the dependencies from `requirements.txt`.
- You update the `.env` file with the correct Foundry endpoint.
- Your terminal is open in the `text-analysis` folder with the active virtual environment.

## Key Tasks

### 01: Prepare the Python environment

Before you run the application, you need to configure the Python environment and install the dependencies it uses.

1. In Visual Studio Code, open the **Extensions** pane and, if it is not already installed, install the **Python** extension.

1. Open the **Command Palette**, run the `Python: Select Interpreter` command, and then select an existing environment or create a new **Venv** environment based on your Python 3.13.x installation.

   > **Tip**: If you are prompted to install dependencies, you can install the ones in the `requirements.txt` file in the `Labfiles/01-analyze-text/Python/text-analysis` folder, but it is OK if you do not. You install them in the next steps.

   > **Tip**: If you prefer to use the terminal, you can create your **Venv** environment with `python -m venv labenv`, and then activate it with `\labenv\Scripts\activate`.

1. In the **Explorer** pane, right-click the `text-analysis` folder and select **Open in Integrated Terminal**. If you prefer, open a terminal from the **Terminal** menu and navigate to `Labfiles/01-analyze-text/Python/text-analysis`.

   > **Note**: Opening the terminal in Visual Studio Code automatically activates the Python environment in many cases. You may need to enable running scripts on your system.

1. Verify that the terminal is open in the `text-analysis` folder and that the prompt includes the `(.venv)` prefix to indicate that the Python environment is active.

1. Install the Azure Language Text Analytics SDK and the other required packages by running the following command:

   ```text
   pip install -r requirements.txt
   ```

   This command installs the packages the patient feedback analysis application needs.

1. Verify that the package installation completes without errors.

### 02: Configure the application endpoint

The application needs the endpoint for your Foundry resource so it can send patient feedback text to Azure Language in Foundry Tools.

1. In the **Explorer** pane, open the `.env` file in the `text-analysis` folder.

1. Update the configuration values to include the **endpoint** for your Foundry project. Copy the value from the Foundry portal.

   > **Important**: Modify the pasted endpoint to remove the `/api/projects/{project_name}` suffix. The endpoint should be in the format `https://{your-foundry-resource-name}.services.ai.azure.com`.

1. Save the modified `.env` file with **Ctrl+S**.

1. Verify that the `.env` file contains the Foundry endpoint up to the `.com` domain only.
