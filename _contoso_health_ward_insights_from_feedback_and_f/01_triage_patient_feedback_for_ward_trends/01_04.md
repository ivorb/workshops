# Task 04 - Analyze ward feedback and protect sensitive information

## Introduction

In this task, you add the text analysis capabilities that Contoso Health needs for a ward-level reporting baseline. You detect language, extract entities, and redact PII so Daniel Cho can start summarizing trends while reducing unnecessary exposure of sensitive data.

## Description

You extend the application in three stages. First, you detect the language of each feedback item. Next, you recognize entities in the text. Finally, you identify and redact PII so the output is safer to review in a healthcare quality improvement context.

## Success Criteria

- The application detects the language of each feedback document.
- The application identifies entities in the patient feedback text.
- The application identifies PII entities and shows redacted text.
- You can run the application successfully after each code change.

## Key Tasks

### 01: Add code to detect language

Now that you have created a client for the API, you use it to detect the language in which each patient feedback document is written.

1. In the code editor, find the comment `Get language`.

1. Add the following code:

   ```python
   # Get language
   detectedLanguage = ai_client.detect_language(documents=[text])[0]
   print('\nLanguage: {}'.format(detectedLanguage.primary_language.name))
   ```

   This code sends the current document to the Text Analytics API and prints the detected primary language.

1. Save your changes with **Ctrl+S**.

1. Re-run the program:

   ```text
   python text-analysis.py
   ```

1. Observe the output and confirm that the language for each review is now identified.

   > **Note**: In this example, each review is analyzed individually, resulting in a separate call to the service for each file. An alternative approach is to create a collection of documents and pass them to the service in a single call. In both approaches, the response from the service consists of a collection of documents, which is why the first and only item is selected with `[0]`.

### 02: Add code to extract entities

Patient feedback often mentions people, places, or time periods. Entity extraction helps Contoso Health identify recurring references that may point to trends across wards.

1. In the code editor, find the comment `Get entities`.

1. Add the following code:

   ```python
   # Get entities
   entities = ai_client.recognize_entities(documents=[text])[0].entities
   if len(entities) > 0:
        print("\nEntities")
        for entity in entities:
            print('\t{} ({})'.format(entity.text, entity.category))
   ```

   This code identifies named entities in each feedback document and prints the entity text and category.

1. Save your changes with **Ctrl+S**.

1. Re-run the program:

   ```text
   python text-analysis.py
   ```

1. Observe the output and review the entities that are detected in the text.

1. Verify that entity categories are displayed for at least some of the review files.

### 03: Add code to redact PII

Healthcare feedback can include sensitive details. PII redaction helps support Olivia Brooks’ privacy and audit expectations by identifying and masking personal information before broader review.

1. In the code editor, find the comment `Get PII`.

1. Add the following code:

   ```python
   # Get PII
   pii_result = ai_client.recognize_pii_entities(documents=[text])[0]
   pii_entities = pii_result.entities
   if len(pii_entities) > 0:
        print("\nPII Entities")
        for pii_entity in pii_entities:
            print('\t{} ({})'.format(pii_entity.text, pii_entity.category)) 
        print("Redacted Text:\n {}".format(pii_result.redacted_text))
   ```

   This code identifies PII entities in each document and prints a redacted version of the original text.

1. Save your changes with **Ctrl+S**.

1. Re-run the program:

   ```text
   python text-analysis.py
   ```

1. Observe the output, noting the PII entities that are identified and the redacted text that is produced.

1. If the app fails because the rate limit is exceeded, wait a few seconds and try again.

1. When you have finished testing, deactivate the Python environment by running:

   ```bash
   deactivate
   ```

1. Verify that the application now detects language, extracts entities, and shows PII redaction results for the feedback files.
