# Task 03 - Create and test an image analyzer for visual reporting content

## Introduction

Ward reporting often includes visual materials such as summary slides or operational review decks. To support analysts such as Daniel Cho and leaders such as Maya Patel, you can extract structured values from images so that chart information and summaries become easier to compare with text-based feedback insights.

## Description

In this task, you create a second custom analyzer that extracts fields from a slide image. You define generated fields, nested list-of-object fields, test the schema, and then build and validate a reusable analyzer.

## Success Criteria

- You have created a second custom project that uses the same Contoso Health resource settings.
- Your schema includes the fields `Title`, `Summary`, `Charts`, `QuarterlyRevenue`, and `ProductCategories`.
- You have reviewed generated values in the **Fields** pane after testing.
- You have built and tested the `slideanalyzer` analyzer successfully.

## Key Tasks

### 01: Create the image analysis project

You create a second project so you can define a schema that is specific to visual content.

1. In the **Project list** tab, select **Create** and select **Extract content and fields with a custom schema**, and then create a project with the following settings:
   - **Project name**: `Slide analysis`
   - **Description**: `Extract data from an image of a slide`
   - **Advanced settings**: *Verify the settings are the same as the last project*

1. Wait for the project to be created.

### 02: Upload the sample image and define the schema

The image analysis template does not include predefined fields, so you define the full schema yourself. This gives you control over the exact output structure.

1. Upload the `slide-1.jpg` file from the folder where you extracted the content files. Then select the **Image analysis** template and select **Save**.

   The **Image analysis** template doesn't include any predefined fields. You must define fields to describe the information you want to extract.

1. Use the **+ Add new field** button to add the following fields, selecting **Save changes** (**&#10003;**) for each new field:

   | Field name | Field description | Value type | Method |
   |--|--|--|--|
   | `Title` | `Slide title` | String | Generate |
   | `Summary` | `Summary of the slide` | String | Generate |
   | `Charts` | `Number of charts on the slide` | Integer | Generate |

1. Use **+ Add new field** to add a new field named `QuarterlyRevenue` with the description `Revenue per quarter` and the value type **List of objects**. Then select the table icon next to the value type dropdown. In the new page for the table subfields, add the following subfields:

   | Field name | Field description | Value type | Method |
   |--|--|--|--|
   | `Quarter` | `Which quarter?` | String | Generate |
   | `Revenue` | `Revenue for the quarter` | Number | Generate |

1. Select **Back** to return to the top level of your schema, and then use **+ Add new field** to add a new field named `ProductCategories` with the description `Product categories` and the value type **List of objects**. Then select the table icon next to the value type to open a new page for the table subfields, and add the following subfields:

   | Field name | Field description | Value type | Method |
   |--|--|--|--|
   | `ProductCategory` | `Product category name` | String | Generate |
   | `RevenuePercentage` | `Percentage of revenue` | Number | Generate |

1. Select **Back** to return to the top level of your schema, and verify that it looks like this. Then select **Save**.

![Screenshot of the image analyzer schema in Content Understanding Studio showing fields for Title, Summary, Charts, QuarterlyRevenue, and ProductCategories.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-information-extraction/main/Instructions/Exercises/media/slide-schema.png)

### 03: Test the schema and review the generated output

Testing the schema helps you confirm that the fields produce meaningful values before you build the analyzer.

1. Select the **Test** tab, and then select **Run analysis** and wait for analysis to complete.
1. Review the analysis results, which should look similar to this:

![Screenshot of image analysis test results in Content Understanding Studio showing extracted fields from the slide including revenue data and product categories.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-information-extraction/main/Instructions/Exercises/media/slide-analysis.png)

1. View the details of the fields that were identified in the **Fields** pane, expanding the **QuarterlyRevenue** and **ProductCategories** fields to see the subfield values.

### 04: Build and test the image analyzer

After confirming the schema works, you build the analyzer and test it with a second image.

1. Select the **Build analyzer** button at the top, and then build a new analyzer with the following properties, typed exactly as shown:
   - **Name**: `slideanalyzer`
   - **Description**: `Slide image analyzer`

1. When the analyzer has been built, select **Jump to analyzer list**, and then select the **slideanalyzer** link. The fields defined in the analyzer's schema are displayed.
1. In the **slideanalyzer** page, select the **Test** tab.
1. Use the **+ Upload test files** button to upload `slide-2.jpg` from the folder where you extracted the content files, and then run the analysis to extract field data from the image.
1. Review the **Fields** pane, and verify that the analyzer extracted the correct fields from the slide image.

   > **Note**: Slide 2 doesn't include a breakdown by product category, so the product category revenue data is not found.

1. Review the **Results** pane to see the JSON response that the analyzer would return to a client application.
1. Close the **slideanalyzer** page.
