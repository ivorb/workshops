# Task 04 - Clean up workshop resources

## Introduction

When you finish exploring Azure Content Understanding, remove any resources you created if you no longer need them. This helps Contoso Health avoid unnecessary Azure costs while keeping the workshop environment tidy.

## Description

In this task, you delete the Azure resources used in this exercise.

## Success Criteria

- You have removed the resources created for this exercise.
- The `rg-contosohealth-workshop` resource group is deleted if you no longer need the workshop environment.

## Key Tasks

### 01: Delete the workshop resources

1. Open the [Azure portal](https://portal.azure.com).
1. Delete the `rg-contosohealth-workshop` resource group if you've finished working with the Azure Content Understanding service used in this exercise.

   This removes the resources you created, including `contosohealth-ai` and `contosohealthstorage`, and helps avoid ongoing Azure charges.
