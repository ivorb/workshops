# Task 01 - Prepare the Contoso Health content understanding workspace

## Introduction

To move from narrative patient feedback to richer ward performance insight, you need a workspace that can analyze files beyond plain text. In this task, you connect Azure Content Understanding tools to the Contoso Health workshop environment so you can work with documents and images using the shared Azure resources.

## Description

You create or confirm the Microsoft Foundry project context, download the sample files for this exercise, explore a prebuilt analyzer, and connect Content Understanding Studio to the existing Contoso Health Azure AI services resource. You also create the storage account and blob container that the custom analyzers will use.

## Success Criteria

- You can open the **Foundry (new)** experience in the Microsoft Foundry portal.
- You have downloaded and extracted the sample content files locally.
- You have successfully tested the **Azure Content Understanding - Layout** analyzer with a sample file.
- Content Understanding Studio is connected to `contosohealth-ai`.
- The storage account `contosohealthstorage` is available for Content Understanding Studio.

## Key Tasks

### 01: Open the workshop project context in Microsoft Foundry

You begin by opening the Foundry environment for the Contoso Health workshop. The features used in this exercise require a Microsoft Foundry resource and project context.

1. Open a web browser and go to the [Microsoft Foundry portal](https://ai.azure.com) at `https://ai.azure.com`, and then sign in using your Azure credentials. Close any tips or quick start panes that appear.
1. Make sure the **New Foundry** toggle is on so that you're using **Foundry (new)**.
1. If you aren't prompted to create a new project automatically, select the project name in the upper-left corner, and then select **Create new project**.
1. Give your project a name and expand **Advanced options** to specify the following settings:
   - **Project name**: *Provide a valid name for your project*
   - **Foundry resource**: *Use the default*
   - **Region**: Choose one of the following supported regions:
     - Australia East
     - East US
     - East US 2
     - Japan East
     - North Europe
     - South Central US
     - Southeast Asia
     - Sweden Central
     - UK South
     - West Europe
     - West US
     - West US 3
   - **Subscription**: *Your Azure subscription*
   - **Resource group**: `rg-contosohealth-workshop`

   > **Note**: Azure Content Understanding is available in selected regions. Choose a supported region for the project resources.

1. Select **Create** and wait for your project to be created.

### 02: Download the sample healthcare workshop files

You need the local sample files before you can test analyzers. These files are used throughout the exercise.

1. Open a new browser tab and download `content.zip` from `https://github.com/microsoftlearning/mslearn-ai-information-extraction/raw/main/Labfiles/content/content.zip`.
1. Save the file in a local folder on your computer.
1. Extract the downloaded `content.zip` file and review the files it contains.

   You use these files to explore Content Understanding analyzers in this exercise.

### 03: Try a prebuilt analyzer in the playground

Before you build a custom schema, review what the prebuilt analyzers can extract automatically. This helps you understand the difference between general extraction and schema-based field extraction.

1. In the [Microsoft Foundry portal](https://ai.azure.com), make sure the **New Foundry** toggle is on.
1. Select **Build** in the upper-right menu, and then select **Deployments** in the left pane.
1. Select the **AI Services** tab to view the prebuilt models provided by Foundry Tools.
1. Find and select **Azure Content Understanding - Layout**.

   This opens the Layout analyzer playground page, where you can test the layout model on sample data or your own files.

1. In the playground, use the option to upload your own data and upload the `invoice-1234.pdf` file from the folder where you extracted the content files. This file contains the following sample document:

![Image of an invoice number 1234.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-information-extraction/main/Instructions/Exercises/media/invoice-1234.png)

1. Run the analyzer and wait for analysis to complete.
1. Review the results. You can view the extracted content either as formatted output or as raw JSON data. Notice that the Layout analyzer extracts text, tables, and structural elements such as paragraphs and sections from the document.

   > **Note**: The prebuilt **Read** and **Layout** analyzers extract content from documents without requiring a generative AI model. **Read** extracts text elements such as words, paragraphs, formulas, and barcodes, while **Layout** also extracts tables, figures, document structure, hyperlinks, and annotations. These analyzers are useful for general-purpose extraction, but they don't extract specific custom fields for reporting.

1. Optionally, go back to the **AI Services** tab and try **Azure Content Understanding - Read** with the same file to compare the results. Notice that Read extracts text without layout analysis.

### 04: Connect Content Understanding Studio to Contoso Health resources

To create custom analyzers, you connect Content Understanding Studio to the Azure AI services resource used in the workshop. This makes the existing Contoso Health environment available for schema design and testing.

1. Open a new browser tab and go to [Content Understanding Studio](https://contentunderstanding.ai.azure.com) at `https://contentunderstanding.ai.azure.com`.
1. If prompted, sign in with the same Azure credentials you used for the Foundry portal.
1. On the **Settings** page, or if you're redirected to set up your resource, select **+ Add resource**.
1. Select the `contosohealth-ai` resource, and then select **Next** > **Save**.

   > **Tip**: Make sure that the **Enable autodeployment for required models if no defaults are available** checkbox is selected. This ensures your resource is set up with the required `GPT-4.1`, `GPT-4.1-mini`, and `text-embedding-3-large` models that custom analyzers need.

1. After your resource is connected, select **Content Understanding** in the top navigation to go to the home page.

### 05: Create the storage account for analyzer project files

Content Understanding Studio requires Azure Blob Storage for project content and analyzer assets. In the Contoso Health workshop, you use the shared storage account name from the blueprint.

1. Open a new browser tab and go to the [Azure portal](https://portal.azure.com) at `https://portal.azure.com`, and then sign in with your Azure credentials.
1. Select **+ Create a resource**, search for `Storage account`, and create a new **Storage account** resource with the following settings:
   - **Subscription**: *Your Azure subscription*
   - **Resource group**: `rg-contosohealth-workshop`
   - **Storage account name**: `contosohealthstorage`
   - **Region**: *The same region as your Foundry resource*
   - **Preferred storage type**: Azure Blob Storage or Azure Data Lake Storage Gen 2
   - **Performance**: Standard
   - **Redundancy**: Locally-redundant storage (LRS)

1. Select **Review + create**, and then select **Create**. Wait for deployment to complete.
1. After the deployment finishes, verify that the `contosohealthstorage` resource appears in the `rg-contosohealth-workshop` resource group.

   You now have the Azure storage dependency needed for custom analyzer projects.
