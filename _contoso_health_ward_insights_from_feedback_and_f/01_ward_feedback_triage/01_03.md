# Task 03 - Connect the app and detect patient feedback language

## Introduction

Before Contoso Health can summarize ward feedback trends, the application must connect to Azure AI Language and process each feedback file correctly. In this task, you add the client connection code and implement language detection so the app can identify the language of each patient comment.

## Description

You update `text-analysis.py` to import the required SDK namespaces, create a `TextAnalyticsClient` with `DefaultAzureCredential`, sign in with Azure CLI, and run the app. Then you add code to detect the language of each review document.

## Success Criteria

- The app authenticates successfully by using `DefaultAzureCredential`.
- `az login` completes successfully in the active environment.
- Running the app displays the feedback text files without errors.
- After your code update, the app displays the detected language for each file.

## Key Tasks

### 01: Add code to create the Azure AI Language client

The starter file already loads the endpoint from configuration. You now add the namespaces and client creation code that lets the application call Azure AI Language securely.

1. In the **Explorer** pane, open `text-analysis.py`.

1. Review the existing code. You will add code to work with the Azure Language Text Analytics SDK.

   > **Tip**: As you add code to the code file, be sure to maintain the correct indentation.

1. Under the existing namespace references, find the comment `Import namespaces` and add the following code:

    ```python
    # import namespaces
    from azure.identity import DefaultAzureCredential
    from azure.ai.textanalytics import TextAnalyticsClient
    ```

   This code imports the Azure identity library for authentication and the client used to call the text analytics service.

1. In the `main` function, find the comment `Create client using endpoint` and add the following code:

    ```python
    # Create client using endpoint
    credential = DefaultAzureCredential()
    ai_client = TextAnalyticsClient(endpoint=foundry_endpoint, credential=credential)
    ```

   This code creates a `TextAnalyticsClient` that uses your Azure sign-in context instead of an API key.

1. Save the file by pressing **Ctrl+S**.

### 02: Sign in to Azure and validate the connection

Before you can run the application locally, you need to sign in so `DefaultAzureCredential` can obtain a token for the Azure resource.

1. In the terminal pane, run the following command:

    ```powershell
    az login
    ```

   This command signs you in to Azure for local development and allows the SDK to authenticate.

1. When prompted, follow the instructions to sign in.

1. Complete the sign-in process in the command line, and confirm that the selected subscription contains the Contoso Health resources.

   > **Note**: In most scenarios, just using `az login` is sufficient. However, if you have subscriptions in multiple tenants, you may need to specify the tenant by using the `--tenant` parameter.

1. Run the application:

    ```text
    python text-analysis.py
    ```

1. Observe the output. The application should run without error and display the contents of each review text file in the `reviews` folder.

1. Verify that the application creates the client successfully even though it does not yet use it for analysis.

### 03: Add code to detect language

Now that the client is working, you can identify the language of each patient feedback document. This is a useful first validation step before ward-level categorization or downstream processing.

1. In `text-analysis.py`, find the comment `Get language`.

1. Add the following code:

    ```python
    # Get language
    detectedLanguage = ai_client.detect_language(documents=[text])[0]
    print('\nLanguage: {}'.format(detectedLanguage.primary_language.name))
    ```

   This code sends the current document to the service and prints the primary detected language.

1. Save the file by pressing **Ctrl+S**.

1. Re-run the application:

    ```text
    python text-analysis.py
    ```

1. Observe the output and verify that the language for each review is now displayed.

   > **Note**: In this example, each review is analyzed individually, resulting in a separate call to the service for each file. An alternative approach is to create a collection of documents and pass them to the service in a single call. In both approaches, the response from the service consists of a collection of documents, which is why the code specifies the first item with `[0]`.

## Description

You have connected the Contoso Health feedback triage app to Azure AI Language and used it to detect the language of each patient feedback file. This confirms that the app can authenticate, call the service, and return structured analysis results.

## Success Criteria

- `az login` completes successfully.
- `python text-analysis.py` runs without authentication or endpoint errors.
- The app prints a detected language for each review document.
