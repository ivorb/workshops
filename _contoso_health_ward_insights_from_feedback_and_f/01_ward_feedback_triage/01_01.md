# Task 01 - Set up the Contoso Health feedback triage workspace

## Introduction

Before you can analyze patient feedback, you need a working Microsoft Foundry project and the starter application files. In this task, you prepare the shared Contoso Health workspace so your code can connect to Azure AI Language and process feedback comments consistently.

## Description

You sign in to the Foundry portal, create or open the workshop project that uses `ai-contosohealth-foundry`, and download the Python starter files. You then confirm where to find the endpoint information that the application will use later.

## Success Criteria

- You can sign in to the Foundry portal successfully.
- You have a project available that uses the shared workshop resources in `rg-contosohealth-workshop`.
- You have cloned the sample repository and opened the `text-analysis` app in Visual Studio Code.
- You know where to find the Foundry project endpoint for later configuration.

## Key Tasks

### 01: Create or open the workshop project in Microsoft Foundry

Microsoft Foundry uses projects to organize models, resources, data, and other assets used to develop an AI solution. For Contoso Health, this project provides the shared connection point for the workshop resources.

1. Open Microsoft Edge and go to the [Microsoft Foundry portal](https://ai.azure.com) at `https://ai.azure.com`.

1. Sign in using your Azure credentials.

1. Close any tips or quick start panes that open the first time you sign in. If necessary, use the Foundry logo at the upper left to return to the home page.

1. If it is not already enabled, in the toolbar at the top of the page, enable the **New Foundry** option.

1. Create a new project if one is not already available for this exercise. If prompted, expand **Advanced options** and specify settings that align to the workshop resources:
   - **Foundry resource**: `ai-contosohealth-foundry`
   - **Subscription**: *Your Azure subscription*
   - **Resource group**: `rg-contosohealth-workshop`
   - **Region**: Select any available region

   > **Note**: Use a recommended Microsoft Foundry region. Model availability may vary by region.

1. Select **Create** and wait for the project to be created.

1. On the home page for your project, note that the API key, project endpoint, and OpenAI endpoint are displayed.

   > **Tip**: You will need the project endpoint later.

1. Verify that the project is associated with the workshop resources for Contoso Health. You should be able to continue using this project throughout the workshop.

### 02: Get the Contoso Health application files from GitHub

The initial application files for the feedback triage prototype are provided in a GitHub repository. You use them as the starting point for the Python application that analyzes patient comments.

1. Open Visual Studio Code.

1. Open the Command Palette by pressing **Ctrl+Shift+P**.

1. Run the `Git:clone` command and clone the `https://github.com/microsoftlearning/mslearn-ai-language` repo to a local folder. Then open the cloned repo in Visual Studio Code.

   You may be prompted to confirm that you trust the authors.

1. In the **Explorer** pane, navigate to the folder that contains the application code at `Labfiles/01-analyze-text/Python/text-analysis`.

1. Review the files in the folder. The application files include:
   - `reviews` — a subfolder containing the review documents
   - `.env` — the application configuration file
   - `requirements.txt` — the Python package dependencies
   - `text-analysis.py` — the code file for the application

1. Verify that you can open each file in Visual Studio Code and that the `reviews` folder contains the text files the app will process.

## Description

You have prepared the shared workspace for Contoso Health's ward feedback triage prototype. The project gives you a connection point into Microsoft Foundry, and the starter files give you the application structure you will complete in the next tasks.

## Success Criteria

- The Foundry project is available and associated with `ai-contosohealth-foundry` and `rg-contosohealth-workshop`.
- The `mslearn-ai-language` repository is cloned locally.
- The `Labfiles/01-analyze-text/Python/text-analysis` folder is open and ready for configuration.
