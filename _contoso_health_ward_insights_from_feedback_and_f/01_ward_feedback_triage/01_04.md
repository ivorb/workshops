# Task 04 - Extract entities and redact PII in patient feedback

## Introduction

Contoso Health needs feedback analysis that is useful for operations while still handling sensitive data carefully. In this task, you enrich the application by extracting named entities from patient comments and redacting personally identifiable information so feedback can be reviewed more safely.

## Description

You update the app to recognize entities such as people, places, and time references in the feedback text. You then add PII detection and redaction so the output is more appropriate for operational review by ward and registration teams.

## Success Criteria

- The app identifies entities found in each feedback document.
- The app detects PII entities when they appear in text.
- The app outputs a redacted version of the text.
- You can explain how this workflow supports privacy-aware ward insight triage.

## Key Tasks

### 01: Add code to extract entities

Named entity recognition helps the clinical operations team understand what people, places, or other important references appear in patient comments.

1. In `text-analysis.py`, find the comment `Get entities`.

1. Add the following code:

    ```python
    # Get entities
    entities = ai_client.recognize_entities(documents=[text])[0].entities
    if len(entities) > 0:
         print("\nEntities")
         for entity in entities:
             print('\t{} ({})'.format(entity.text, entity.category))
    ```

   This code requests entity recognition for the current feedback document and prints each detected entity and category.

1. Save the file by pressing **Ctrl+S**.

1. Run the application:

    ```text
    python text-analysis.py
    ```

1. Review the output and note the entities that are detected in the text.

1. Verify that the app now provides more structured insight from each feedback comment.

### 02: Add code to redact PII

Patient feedback can include names, contact details, and other sensitive information. PII detection and redaction help Contoso Health support privacy-aware operational review without changing the source system.

1. In `text-analysis.py`, find the comment `Get PII`.

1. Add the following code:

    ```python
    # Get PII
    pii_result = ai_client.recognize_pii_entities(documents=[text])[0]
    pii_entities = pii_result.entities
    if len(pii_entities) > 0:
         print("\nPII Entities")
         for pii_entity in pii_entities:
             print('\t{} ({})'.format(pii_entity.text, pii_entity.category)) 
         print("Redacted Text:\n {}".format(pii_result.redacted_text))
    ```

   This code identifies PII in the text, lists the detected entities, and prints a redacted version of the document.

1. Save the file by pressing **Ctrl+S**.

1. Re-run the application:

    ```text
    python text-analysis.py
    ```

1. Observe the output and review both the detected PII entities and the redacted version of each document.

1. Confirm that the application now performs all of the following for each feedback file:
   - Displays the original text
   - Detects the language
   - Extracts entities
   - Identifies and redacts PII

1. When you have finished testing, deactivate the Python environment by running:

    ```bash
    deactivate
    ```

   > **Tip**: If the app fails because the rate limit is exceeded, wait a few seconds and try again.
