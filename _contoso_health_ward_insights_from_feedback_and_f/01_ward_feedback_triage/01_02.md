# Task 02 - Configure the Python application

## Introduction

To support a reliable healthcare text analysis workflow, your development environment needs the correct Python interpreter, dependencies, and endpoint configuration. In this task, you prepare the application so it can authenticate securely and connect to `cog-contosohealth-lang` through the Foundry endpoint.

## Description

You create or select a Python virtual environment, install the required packages, and update the `.env` file with the Foundry endpoint for the Contoso Health project.

## Success Criteria

- A Python 3.13 virtual environment is active in Visual Studio Code.
- The required Python packages are installed successfully.
- The `.env` file contains the correct Foundry endpoint value.
- The terminal is open in the `text-analysis` folder and ready to run commands.

## Key Tasks

### 01: Prepare the Python environment

The application uses the Azure Language Text Analytics SDK for Python. Before you write or run code, make sure Visual Studio Code is using a supported Python environment.

1. In Visual Studio Code, open the **Extensions** pane.

1. Install the **Python** extension if it is not already installed.

1. Open the Command Palette by pressing **Ctrl+Shift+P**.

1. Run the `python:select interpreter` command.

1. Select an existing environment if you have one, or create a new **Venv** environment based on your Python 3.13.x installation.

   > **Tip**: If you are prompted to install dependencies, you can install the ones in the `requirements.txt` file in the `Labfiles/01-analyze-text/Python/text-analysis` folder, but it is also fine to install them in the next step.

   > **Tip**: If you prefer to use the terminal, you can create your **Venv** environment with `python -m venv labenv`, then activate it with `\labenv\Scripts\activate`.

1. In the **Explorer** pane, right-click the `text-analysis` folder and select **Open in Integrated Terminal**.

1. Confirm that the terminal opens in the `text-analysis` folder and that the prompt shows the active environment, such as `(.venv)`.

### 02: Install dependencies and configure the endpoint

Now install the packages that the application needs and configure the endpoint value it will use to connect through Foundry.

1. In the integrated terminal, run the following command to install the required packages:

    ```text
    pip install -r requirements.txt
    ```

   This command installs the Azure Language SDK and the supporting packages used by the application.

1. In the **Explorer** pane, open the `.env` file.

1. Update the configuration values so the file includes the **endpoint** for your Foundry project. Copy the value from the Foundry portal.

   > **Important**: Modify the pasted endpoint to remove the `/api/projects/{project_name}` suffix. The endpoint should be in the format `https://{your-foundry-resource-name}.services.ai.azure.com`.

1. Save the `.env` file by pressing **Ctrl+S**.

1. Verify that the endpoint value ends at the `.com` domain and does not include the project path suffix.

## Description

Your Python environment is now ready for secure local development. The application can use the configured endpoint to reach the shared Contoso Health Foundry resource, which is backed by `cog-contosohealth-lang` for text analysis.

## Success Criteria

- `pip install -r requirements.txt` completes without errors.
- The terminal remains in the `text-analysis` folder with the virtual environment active.
- The `.env` file contains a valid endpoint in the format `https://{your-foundry-resource-name}.services.ai.azure.com`.
