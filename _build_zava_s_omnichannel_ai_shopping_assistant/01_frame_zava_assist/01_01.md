# Task 01 - Create the shared Zava Assist project

## Introduction

In this task, you create the shared Microsoft Foundry project that Zava uses as the foundation for the workshop. This matters because Ethan Brooks needs a repeatable development environment, and the rest of the Zava team depends on a consistent Azure setup for later agent and app work.

## Description

You sign in to the Foundry portal, create the `aiproj-zava-assist` project in the `rg-zava-workshop` resource group, and verify that the project is ready to support the Zava Assist solution.

## Success Criteria

- You sign in to the Foundry portal successfully.
- You create a project named `aiproj-zava-assist`.
- The project uses the `rg-zava-workshop` resource group.
- The project home page opens after deployment.

## Key Tasks

### 01: Review the prerequisites

Before you create the shared environment, confirm that your workstation is ready for the rest of the workshop.

1. Verify that you have the following prerequisites:
   - An active [Azure subscription](https://azure.microsoft.com/pricing/purchase-options/azure-account)
   - [Visual Studio Code](https://code.visualstudio.com/) installed
   - [Python version **3.13.xx**](https://www.python.org/downloads/release/python-31312/) installed
   - [Git](https://git-scm.com/install/) installed and configured
   - [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli?view=azure-cli-latest) installed

1. Note that Python 3.14 is available, but some dependencies are not yet compiled for that release. This workshop has been successfully tested with Python 3.13.12.

> **Note**: Some of the technologies used in this exercise are in preview or in active development. You may experience some unexpected behavior, warnings, or errors.

### 02: Create the Foundry project

Microsoft Foundry uses projects to organize models, resources, data, and other assets used to develop an AI solution. In this workshop, `aiproj-zava-assist` becomes the shared development space for Zava Assist.

1. Open Microsoft Edge and go to the [Microsoft Foundry portal](https://ai.azure.com) at `https://ai.azure.com`.

1. Sign in by using your Azure credentials.

1. Close any tips or quick start panes that open the first time you sign in.

1. If it is not already enabled, on the toolbar at the top of the page, enable **New Foundry**.

1. Create a new project and expand **Advanced options**.

1. Enter or select the following settings:
   - **Project name**: `aiproj-zava-assist`
   - **Foundry resource**: Use the default name for your resource
   - **Subscription**: Your Azure subscription
   - **Resource group**: `rg-zava-workshop`
   - **Region**: Select any of the **AI Foundry recommended** regions in the region availability list

1. Make a note of the region that you select. You use it later in the workshop.

1. Select **Create**.

1. Wait for the project to be created.

1. Verify that the project home page opens when provisioning finishes.

You should now see the home page for `aiproj-zava-assist`, which confirms that the shared Zava Assist project is ready.
