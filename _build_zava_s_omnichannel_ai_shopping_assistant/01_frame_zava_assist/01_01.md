# Task 01 - Create the shared Zava Assist project foundation

## Introduction

In this task, you create the shared AI project foundation for Zava Assist. This matters because Priya Nair needs a consistent Azure setup and naming approach that the rest of the workshop can build on, while Maya Patel needs confidence that the prototype starts from a governed, reusable project space.

## Description

You use Microsoft Foundry portal to create the workshop project for Zava Assist. As you do this, you align the environment to Zava's retail scenario and prepare the shared foundation that later exercises use for agents, escalation workflows, and multimodal chat experiences.

## Success Criteria

- You sign in to Microsoft Foundry portal successfully.
- You create or open the shared project foundation for Zava Assist.
- You use the workshop resource names where applicable, including `rg-zava-workshop` and `ai-zava-foundry`.
- You reach the project home page and confirm that the environment is ready for model work.

## Key Tasks

### 01: Create the Foundry project for Zava Assist

Microsoft Foundry uses projects to organize models, resources, data, and other assets used to develop an AI solution. For Zava, this shared project becomes the starting point for the retail assistant that serves shoppers and associates across channels.

1. Open Microsoft Edge, and then open the [Microsoft Foundry portal](https://ai.azure.com) at `https://ai.azure.com` to start building; signing in using your Azure credentials. Close any tips or quick start panes that are opened the first time you sign in.

1. If it is not already enabled, in the tool bar at the top of the page, enable the **New Foundry** option. Then, create a new project with a unique name for the Zava workshop; expanding the **Advanced options** area to specify the following settings for your project:
   - **Foundry resource**: `ai-zava-foundry`
   - **Subscription**: *Your Azure subscription*
   - **Resource group**: `rg-zava-workshop`
   - **Region**: Select any of the **AI Foundry recommended** regions in **[this list](https://learn.microsoft.com/azure/foundry/openai/how-to/responses#region-availability)**{:target="_blank"}

   > **Tip**: Make a note of the region you selected. You'll need it later as you continue building Zava Assist.

1. Select **Create**. Wait for your project to be created.

   When it is ready, the project home page will open.

![Screenshot of the Foundry project home page.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-studio/main/Instructions/media/foundry-portal-home.png)

1. Review the home page and confirm that the project opens successfully for the Zava workshop environment.

   You should now see the project home page for the shared Zava Assist foundation. This confirms that the workshop environment is ready for the next task.
