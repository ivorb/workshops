# Task 03 - Review the Zava Assist project and resource endpoints

## Introduction

A working deployment is only part of the setup. You also need to understand how the Foundry project relates to the parent resource and which endpoints support future application development. This matters because Ethan Brooks needs the correct connection details before he can build agents and applications for Zava Assist.

## Description

You open the **Operate** and **Admin** experiences, inspect the parent resource, and identify the key, project endpoint, and Azure OpenAI endpoint for the shared environment.

## Success Criteria

- You open the **Operate** center.
- You review the **Admin** page for the project.
- You open the **Parent resource** details.
- You identify the key, project endpoint, and Azure OpenAI endpoint from the project home page.

## Key Tasks

### 01: Open the project administration experience

The operation center is where you can monitor projects, view alerts, monitor agent performance and quotas, and manage resources.

1. In the Foundry portal, on the top menu bar, select **Operate**.

1. In the left navigation pane, select **Admin**.

1. Review the project details that are shown.

The *resource* level relates to the Foundry resource that was created in Azure to support your project. This resource includes connections to Foundry Services and models and provides a central place to manage user access to AI development projects.

The *project* level relates to your individual project, where you can add and manage project-specific resources. A resource can support multiple projects, and the first one created is the resource's default project.

1. Verify that you can see the administration details for `aiproj-zava-assist`.

### 02: Review the parent resource

The parent resource contains resource-level capabilities that can be shared across projects.

1. On the **Admin** page, select the link for the **Parent resource** associated with the project.

1. Review the resource configuration details.

1. Note that the Foundry resource has an endpoint through which client applications can access resource-level functionality, such as shared tools.

1. Verify that the parent resource details page displays successfully.

### 03: Identify the project and model connection details

These connection details are important because later workshop exercises use them to access models and project-level capabilities.

1. On the top menu bar, select **Home** to return to the `aiproj-zava-assist` project home page.

1. Locate and review the key, project endpoint, and Azure OpenAI endpoint.

1. Note the purpose of each value:
   - The *key* is used for key-based authentication to models and tools, though in most production scenarios you should consider using Microsoft Entra ID authentication based on authenticated user and application identities.
   - The *project endpoint* is used to access models provided directly in Foundry, including OpenAI models, by using the OpenAI **Responses** API and to access Foundry-specific APIs such as the Foundry Agent service.
   - The *OpenAI endpoint* is used to access models by using OpenAI APIs, including the **Chat Completions** API and the **Responses** API.

1. Verify that you can distinguish between the project endpoint and the Azure OpenAI endpoint before moving on.

You now have the environment details that support later code and agent integration work for Zava Assist.
