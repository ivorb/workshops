# Task 02 - Deploy and test the core model

## Introduction

Now that the shared project exists, you need at least one deployed model to support early experimentation. This matters because Maya Patel and Sofia Ramirez need a working assistant experience later in the workshop, and you need a tested model deployment before you build on top of it.

## Description

You explore the model catalog, deploy `gpt-5.2`, and test it in the playground by re-framing the assistant around Zava’s retail scenario.

## Success Criteria

- You locate the `gpt-5.2` model in the catalog.
- You deploy the model with the default settings.
- The model playground opens automatically.
- You submit a Zava-focused prompt and receive a response.

## Key Tasks

### 01: Explore the model catalog

The model catalog helps you review available models and their capabilities before deployment.

1. In the Foundry portal for `aiproj-zava-assist`, go to the **Discover** page.

1. Select the **Models** tab.

1. Search for `gpt-5.2`.

1. Select the `gpt-5.2` model in the search results to open its model card.

Model cards provide information about models to help you understand their capabilities and limitations, and determine if they are suitable for your requirements.

1. Review the model card details.

1. Verify that you can see the model information and deployment option before you continue.

### 02: Deploy the model

Model deployments enable you to work with a model in your project and reuse it in later exercises.

1. On the `gpt-5.2` model card, select **Deploy**.

1. Accept the default settings to create the deployment.

1. Wait for the deployment to finish.

1. Verify that the model playground opens automatically after deployment completes.

You should now see the playground for the deployed `gpt-5.2` model in `aiproj-zava-assist`.

### 03: Test the model in the playground

Testing the deployment now confirms that the shared environment is working before you move on to agent and application development.

1. In the **Instructions** box, enter the following instructions:

    ```text
    You are Zava Assist, an AI shopping assistant for a retail DIY chain. You provide product guidance, shopping assistance, and responsible AI-aware support for online shoppers and store associates.
    ```

This instruction sets the model behavior for the Zava retail scenario.

1. In the chat window, enter the following query:

    ```text
    Describe three key considerations for building an AI shopping assistant for a retail business that serves customers online and in stores.
    ```

1. Review the response.

1. Verify that the response includes relevant considerations such as product accuracy, safety, escalation, customer experience, or omnichannel consistency.

> **Tip**: If the app fails because the rate limit is exceeded, wait a few seconds and try again.
