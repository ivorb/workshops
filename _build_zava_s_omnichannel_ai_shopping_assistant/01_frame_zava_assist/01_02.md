# Task 02 - Deploy and test the baseline model

## Introduction

In this task, you deploy the core model that Zava Assist will use as an initial language capability. This matters because Sofia Rossi and Ethan Brooks need the assistant to provide grounded, useful product guidance, and every later exercise depends on having a model deployment available in the project.

## Description

You explore the model catalog, review the `gpt-5.2` model card, deploy the model, and test it in the playground. The technical workflow stays the same, but you frame the model as the first reasoning component in Zava's retail assistant solution.

## Success Criteria

- You find the `gpt-5.2` model in the model catalog.
- You review the model card before deployment.
- You deploy the model with the default settings.
- You test the deployment in the playground and receive a valid response.

## Key Tasks

### 01: Explore the model catalog

At the core of any generative AI project, there's at least one generative AI model. For Zava Assist, this first deployment gives you a baseline model that you can later extend with agents, workflows, and multimodal capabilities.

1. On the **Discover** page, select the **Models** tab to view the Microsoft Foundry model catalog.

1. Search for the `gpt-5.2` model, and then select it in the search results to view its model card.

   Model cards provide information about models to help you understand their capabilities and limitations, and determine if they are suitable for your requirements.

![Screenshot of the gpt-5.2 model card.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-studio/main/Instructions/media/gpt5.2-details.png)

1. Review the model card details and confirm that you can inspect the model before deploying it.

   You should now be on the `gpt-5.2` model card page.

### 02: Deploy the model for the workshop project

Model deployments enable you to work with a model in your project. In this workshop, the deployment becomes the starting point for the Zava Assist solution.

1. Select **Deploy** with the default settings to create a deployment of the model.

   When the model has been deployed, the model playground will open automatically so you can test your model:

![Screenshot of the Foundry project model playground.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-studio/main/Instructions/media/ai-foundry-model-playground.png)

1. Wait for the deployment to complete and confirm that the playground opens.

   You should now see the model playground for the deployed `gpt-5.2` model.

### 03: Test the model in the playground

Before you build more solution components, verify that the deployment responds correctly. This helps you confirm that the shared Zava project foundation is working as expected.

1. In the **Instructions** box, enter the following instructions:

   ```text
   You are an AI assistant that can provide information and advice about AI software development.
   ```

   This instruction defines the behavior for your test conversation in the playground.

1. In the chat window, enter a query such as `Describe three key considerations for working with Large Language Models for AI application development.` and view the response.

1. Review the response and confirm that the model returns a useful answer.

   Hopefully the model provided some key considerations for you to think about. This confirms that the deployment is ready to support later Zava Assist development work.
