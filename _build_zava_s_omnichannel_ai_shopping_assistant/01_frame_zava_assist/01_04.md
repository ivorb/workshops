# Task 04 - Connect Visual Studio Code to the shared Foundry project

## Introduction

You spend time in the Foundry portal, but most development work happens in Visual Studio Code. Connecting the shared project to the AI Toolkit gives you a developer-friendly way to inspect models and work with Zava Assist resources without leaving your coding environment.

## Description

You install the AI Toolkit extension for Visual Studio Code, connect it to Azure, set `aiproj-zava-assist` as the default project, and open the deployed model in the playground.

## Success Criteria

- You install the **AI Toolkit** extension in Visual Studio Code.
- You connect the extension to Azure.
- You set `aiproj-zava-assist` as the default project.
- You can view the deployed `gpt-5.2` model and open the playground in Visual Studio Code.

## Key Tasks

### 01: Install the AI Toolkit extension

The AI Toolkit extension provides a convenient way to work with Foundry project resources from Visual Studio Code.

1. Start Visual Studio Code.

1. In the navigation bar on the left, open the **Extensions** page.

1. Search the extensions marketplace for `Foundry Toolkit`.

1. Install the **Foundry Toolkit for VS Code** extension.

The extension may take a minute or so to install.

1. Verify that installation completes successfully.

### 02: Connect the extension to the Zava project

After installation, you connect the extension to Azure and set the workshop project as the default context.

1. In the left navigation bar, select the **Foundry Toolkit** page.

1. Wait for the extension to finish loading.

1. In the Foundry Toolkit pane, expand **Microsoft Foundry Resources**.

1. Connect to Azure by signing in with your credentials.

1. Set the default project by selecting `aiproj-zava-assist`.

1. Verify that the project appears under the extension after the connection is established.

### 03: Review the deployed model in Visual Studio Code

Once the project is connected, you can inspect the deployed model and use the integrated playground directly from Visual Studio Code.

1. In the Foundry Toolkit pane, expand the `aiproj-zava-assist` project.

1. Expand **Models**.

1. Select the `gpt-5.2` model that you deployed earlier.

1. Review the model deployment details.

1. Verify that you can see the deployment information in Visual Studio Code.

### 04: Open the model playground from Visual Studio Code

Opening the playground in Visual Studio Code confirms that your local development environment is connected correctly to the shared Zava Assist resources.

1. In the Foundry Toolkit pane, in the **Developer Tools** section, expand **Build**.

1. Select **Model playground**.

1. Select the `gpt-5.2` model if it is not already selected.

1. Wait for the interactive playground to open in Visual Studio Code.

1. Verify that the playground loads successfully and is ready for use.

At this point, the Zava Assist workshop environment is available both in the Foundry portal and in Visual Studio Code, which prepares you for the next exercise.
