# Task 04 - Connect Visual Studio Code with Foundry Toolkit

## Introduction

In this task, you connect the Zava Assist project to your developer environment. This matters because the workshop continues beyond the portal, and Priya Nair needs a smooth path from Azure setup into Visual Studio Code for model, agent, and application development.

## Description

You install Foundry Toolkit for Visual Studio Code, sign in to Azure, set the Zava workshop project as the default project, review the deployed model, and open the model playground in Visual Studio Code. This confirms that the shared environment works in both the portal and the local development experience.

## Success Criteria

- You install the **Foundry Toolkit for VS Code** extension.
- You sign in and connect the toolkit to the Zava workshop project.
- You locate the deployed `gpt-5.2` model in the toolkit.
- You open and verify the model playground in Visual Studio Code.

## Key Tasks

### 01: Install Foundry Toolkit

As a developer, you may spend some time working in the Foundry portal; but you're also likely to spend a lot of time in Visual Studio Code. The Foundry Toolkit extension provides a convenient way to work with Foundry project resources without leaving the development environment.

1. Start Visual Studio Code.

1. In the navigation bar on the left, view the **Extensions** page.

1. Search the extensions marketplace for `Foundry Toolkit`, and install the **Foundry Toolkit for VS Code** extension.

   The extension may take a minute or so to install.

1. After installing the extension, select the **Foundry Toolkit** page in the left navigation bar; and wait for it to load.

![Screenshot of the Foundry Toolkit Visual Studio Code extension.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-studio/main/Instructions/media/foundry-vs-extension.png)

1. Confirm that the Foundry Toolkit pane opens successfully.

   You should now see the toolkit ready for Azure sign-in and project selection.

### 02: Connect the toolkit to the workshop project

Connecting the toolkit to the correct project ensures that your later exercises target the shared Zava Assist environment instead of a different Azure project.

1. In the Foundry Toolkit pane, expand **Microsoft Foundry Resources** and set the default project by connecting to Azure (signing in with your credentials) and selecting the Foundry project you created previously.

1. After setting the default project, expand the project, expand **Models**, and select the **gpt-5.2** model you deployed previously.

   You can view the model deployment details here.

![Screenshot of a model in the  Foundry Toolkit Visual Studio Code extension.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-studio/main/Instructions/media/vscode-extension-model.png)

1. Review the model details and confirm that the deployed model appears under the connected Zava workshop project.

   You should now see the `gpt-5.2` deployment in the toolkit.

### 03: Open the model playground in Visual Studio Code

Testing the model inside Visual Studio Code confirms that your development workflow is connected end to end. This is the setup you use in later workshop exercises as you build more of Zava Assist.

1. In the Foundry Toolkit pane, in the **Developer Tools** section, expand **Build** and select **Model playground**. Then select the **gpt-5.2** model (if it is not already selected).

   An interactive playground in which you can test the model is opened in Visual Studio Code.

![Screenshot of the model playground in Visual Studio Code.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-studio/main/Instructions/media/vscode-model-playground.png)

1. Review the playground and confirm that the model opens successfully in Visual Studio Code.

   You should now have a working development environment for the rest of the workshop.

1. When you finish validating the environment, keep your project details and endpoint notes available for the next exercise.

   At this point, the shared Azure and developer foundation for Zava Assist is ready.
