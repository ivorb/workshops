# Task 02 - Prepare the Zava visual product finder app

## Introduction

Now that you have confirmed the model can process images, you prepare the local development environment for Zava's prototype. This app becomes the starting point for a visual shopping assistant that can combine customer questions with product or part images.

## Description

In this task, you clone the sample repository, create or select a Python environment, open the application files, and configure the app to connect to Zava's shared Azure OpenAI resource.

## Success Criteria

- The sample repository is cloned locally and opened in Visual Studio Code.
- A Python environment is selected or created in VS Code.
- You can locate the app files in `/labfiles/gen-ai-vision/python`.
- The `.env` file contains the correct Azure OpenAI endpoint and model deployment name.
- Required Python packages are installed successfully.

## Key Tasks

### 01: Get the application files

1. Open Visual Studio Code.

1. Open the command palette with **Ctrl+Shift+P**, run the `Git: Clone` command, and clone `https://github.com/microsoftlearning/mslearn-ai-vision` to a local folder.

1. Open the cloned repository in Visual Studio Code.

1. If prompted, confirm that you trust the authors.

1. In Visual Studio Code, open the **Extensions** pane, and install the **Python** extension if it is not already installed.

1. Open the command palette with **Ctrl+Shift+P**, run the `Python: Select Interpreter` command, and select an existing environment or create a new **Venv** environment based on your Python 3.13.x installation.

    > **Tip**: If you are prompted to install dependencies, you can install the ones in the `requirements.txt` file in the `/labfiles/gen-ai-vision/python` folder later in this task.

1. Verify that Visual Studio Code shows a Python interpreter associated with your selected environment.

### 02: Review the application files

1. In Visual Studio Code, open the folder that contains the app files by selecting **File** > **Open Folder** and navigating to `/labfiles/gen-ai-vision/python`.

1. In the **Explorer** pane, review the files in the folder:

    - `.env` - A configuration file for application settings.
    - `image-chat-app.py` - The Python code file for the image application.
    - `requirements.txt` - A file listing the package dependencies.
    - `mystery-fruit.jpeg` - An image file used by the app.

1. Verify that you can see all four files in the **Explorer** pane.

### 03: Configure the app connection settings

1. In the **Explorer** pane, open the `.env` file.

1. Update the configuration values to include:
    - The **Azure OpenAI endpoint** for `aoai-zava-shop`.
    - The model deployment name for the generative AI model you deployed or reused in the workshop.

    > **Important**: Be sure to add the `https://{foundry-resource-name}.openai.azure.com/openai/v1/` Azure OpenAI endpoint, not the project endpoint.

1. Save the modified `.env` file with **Ctrl+S**.

1. Verify that the `.env` file now contains both the endpoint and deployment settings the app needs.

### 04: Install the Python dependencies

1. In the **Explorer** pane, right-click the `python` folder that contains the application files, and select **Open in Integrated Terminal**.

1. Ensure that the terminal opens in the `/labfiles/gen-ai-vision/python` folder and that the prompt includes `(.venv)` if you are using a virtual environment.

1. Install the required Python packages by running the following command:

    ```text
    pip install -r requirements.txt
    ```

1. Wait for package installation to complete.

1. Verify that the dependencies install successfully and that no blocking errors remain before you continue.
