# Task 01 - Validate the shared vision-ready model in Foundry

## Introduction

Before you write application code for Zava's shopping assistant, you verify that the shared Foundry environment can handle image-based prompts. This gives you confidence that the model and endpoint you use in code can support real retail scenarios such as product identification from customer photos.

## Description

In this task, you open the Microsoft Foundry portal, confirm access to the shared project resources, and test the deployed model in the chat playground with an uploaded image.

## Success Criteria

- You can open the Microsoft Foundry portal and access the shared project environment.
- You can locate the deployed model for the workshop.
- You can submit an image and prompt in the chat playground.
- You receive a relevant response based on the uploaded image.

## Key Tasks

### 01: Open the shared Foundry environment

1. Open the Microsoft Foundry portal in a browser at `https://ai.azure.com`, and sign in with your Azure credentials.

1. Close any tips or quick-start panes that open automatically.

1. If it is not already enabled, on the toolbar at the top of the page, enable **New Foundry**.

1. Open the shared Zava project environment associated with `ai-zava-foundry`.

1. Review the project home page and note the displayed connection details, including the project endpoint and the Azure OpenAI endpoint.

    > **Tip**: You need the Azure OpenAI endpoint later when you configure the client application. Use the Azure OpenAI endpoint, not the project endpoint, when you connect with the OpenAI SDK.

1. Verify that you can access the project successfully. You should see the shared workspace for Zava's workshop resources.

### 02: Locate the deployed model

1. In the Foundry portal, go to the **Discover** page and select the **Models** tab.

1. Locate the model deployment that was created for the workshop. If you are continuing from exercise 01, use the same deployment you created there.

1. Open the model playground page for the deployment.

1. Verify that the chat playground loads successfully and is ready to accept prompts.

### 03: Test image input in the playground

1. In a new browser tab, download `mango.jpeg` from `https://microsoftlearning.github.io/mslearn-ai-vision/Labfiles/gen-ai-vision/mango.jpeg` and save it to a local folder.

1. Return to the chat playground page for your model deployment in the Foundry portal.

1. In the main chat session panel, under the chat input box, use the attach button (**&#128206;**) to upload the `mango.jpeg` image file.

1. Enter the following prompt and submit it:

    ```text
    What desserts could I make with this fruit?
    ```

![Screenshot of the chat playground page.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-vision/main/Instructions/media/chat-playground-image-new.png)

1. Review the response.

1. Verify that the model returns a sensible answer based on the uploaded image, such as dessert ideas that use a mango.
