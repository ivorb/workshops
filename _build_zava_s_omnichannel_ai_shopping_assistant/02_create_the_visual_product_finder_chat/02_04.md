# Task 04 - Run and extend the visual product finder

## Introduction

The final step is to validate the experience end to end and then extend it to use a local image file. This reflects how Zava customers or store associates might provide a photo from a phone, desktop, or local workflow instead of a hosted image URL.

## Description

In this task, you sign in to Azure, run the app, test a URL-based image request, then modify the code to upload a local image file and test that flow as well.

## Success Criteria

- You can authenticate to Azure with the Azure CLI.
- The app runs successfully from the terminal.
- The app returns a relevant answer for a URL-based image prompt.
- The app is updated to use a local image file.
- The app returns a relevant answer for the local image prompt.

## Key Tasks

### 01: Sign in to Azure and test the URL-based image flow

1. In the terminal pane in Visual Studio Code, sign in to Azure by running the following command:

    ```powershell
    az login
    ```

1. When prompted, follow the sign-in instructions in the browser and complete the process by confirming the subscription that contains `rg-zava-workshop`.

    > **Note**: In most scenarios, just using `az login` is sufficient. However, if you have subscriptions in multiple tenants, you may need to specify the tenant by using the `--tenant` parameter.

1. After you have signed in, run the application:

    ```text
    python image-chat-app.py
    ```

1. When prompted, enter the following text:

    ```input
    Suggest some recipes that include this fruit
    ```

1. Review the response returned by the app.

1. Enter `quit` to exit the program.

1. Verify that the app can authenticate and return a valid answer based on the image URL.

    > **Tip**: If the app fails because the rate limit is exceeded, wait a few seconds and try again.

### 02: Modify the app to upload a local image file

1. In the code editor, find the code you added previously under the comment `Get a response to image input`.

1. Replace that code with the following version so the app uploads a local image file instead of using a hosted URL:

![A photo of a dragon fruit.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-vision/main/Instructions/media/mystery-fruit.jpeg)

    ```python
    # Get a response to image input
    image_path = Path("mystery-fruit.jpeg")
    image_format = "jpeg"
    with open(image_path, "rb") as image_file:
         image_data = base64.b64encode(image_file.read()).decode("utf-8")

    data_url = f"data:image/{image_format};base64,{image_data}"

    response = client.responses.create(
         model=model_deployment,
         input=[
             {"role": "developer", "content": system_message},
             { "role": "user", "content": [  
                 { "type": "input_text", "text": prompt},
                 { "type": "input_image", "image_url": data_url}
             ]} 
         ]
    )
    print(response.output_text)
    ```

1. Review the updated code. It reads the local `mystery-fruit.jpeg` file, encodes it as base64, builds a data URL, and submits that image content with the prompt.

1. Save the file with **Ctrl+S**.

1. Verify that the updated code replaces the earlier URL-based version in the same `Get a response to image input` section.

### 03: Run the app with a local image

1. In the terminal, run the app again:

    ```text
    python image-chat-app.py
    ```

1. When prompted, enter the following text:

    ```input
    What is this fruit? What recipes could I use it in?
    ```

1. Review the response.

1. Enter `quit` to exit the program.

1. Verify that the app can analyze the local image and provide a relevant answer.

1. When you have finished testing, deactivate the Python environment by running:

    ```bash
    deactivate
    ```

1. Note that this simple app does not retain conversation history, so each prompt is treated as a new request with no context from previous prompts.

### 04: Clean up the workshop resources if needed

1. If you have finished exploring the Azure AI resources used in this exercise and do not plan to continue with the workshop, open the Azure portal at `https://portal.azure.com`.

1. Open the `rg-zava-workshop` resource group.

1. On the toolbar, select **Delete resource group**.

1. Enter `rg-zava-workshop`, and confirm that you want to delete it.

1. Verify that the deletion process starts successfully.

    > **Important**: If you plan to continue to the next exercise in the workshop, do not delete the shared resources yet.
