# Task 03 - Add OpenAI client code for retail image chat

## Introduction

With the environment ready, you can connect the app to Zava's shared Azure OpenAI deployment. This is the core integration step that enables the shopping assistant to send combined text and image requests to the model.

## Description

In this task, you update the Python app to import the required SDK libraries, create an authenticated OpenAI client by using `DefaultAzureCredential`, and submit a URL-based image prompt that simulates a shopper asking about an item.

## Success Criteria

- The app imports the required OpenAI and Azure Identity namespaces.
- The app creates an authenticated client with `DefaultAzureCredential`.
- The app sends a prompt that includes both text and an image URL.
- The code is saved without syntax errors.

## Key Tasks

### 01: Add the SDK references

1. In Visual Studio Code, open the `image-chat-app.py` file.

1. Review the existing import statements at the top of the file.

1. Find the comment `Add references`, and add the following code:

    ```python
    # Add references
    from openai import OpenAI
    from azure.identity import DefaultAzureCredential, get_bearer_token_provider
    ```

1. Save the file with **Ctrl+S**.

1. Verify that the new imports appear directly under the `Add references` comment.

### 02: Create the authenticated OpenAI client

1. In the `main` function, review the code under the comment `Get configuration settings`.

1. Confirm that the code reads the OpenAI endpoint and model deployment values from the `.env` file.

1. Find the comment `Create an OpenAI client`, and add the following code:

    ```python
    # Create an OpenAI client
    credential = DefaultAzureCredential()
    token_provider = get_bearer_token_provider(credential, "https://ai.azure.com/.default")
    client = OpenAI(
        base_url=openai_endpoint,
        api_key=token_provider()
    )
    ```

1. Save the file with **Ctrl+S**.

1. Verify that the client code is indented correctly inside the `main` function.

    > **Tip**: As you add code, be sure to maintain the correct indentation.

### 03: Add URL-based image input for a retail-style prompt flow

1. In the app's loop section, find the comment `Get a response to image input`.

1. Add the following code under that comment:

![A photo of an orange.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-vision/main/Instructions/media/orange.jpeg)

    ```python
    # Get a response to image input
    image_url = "https://microsoftlearning.github.io/mslearn-ai-vision/Labfiles/gen-ai-vision/orange.jpeg"
    response = client.responses.create(
         model=model_deployment,
         input=[
             {"role": "developer", "content": system_message},
             { "role": "user", "content": [  
                 { "type": "input_text", "text": prompt},
                 { "type": "input_image", "image_url": image_url}
             ]} 
         ]
    )
    print(response.output_text)
    ```

1. Review the code you added. It sends the shopper's prompt together with an image URL so the model can use both text and visual input in the same request.

1. Save the file with **Ctrl+S**.

1. Verify that the code appears in the loop section under the `Get a response to image input` comment and that the file has no obvious indentation issues.
