# Task 02 - Validate the agent in Visual Studio Code

## Introduction

Liam Chen needs a workflow that supports both portal-based configuration and developer tooling in Visual Studio Code. Validating the agent in the extension helps you confirm that Zava's shared Foundry environment is usable from the development experience before you write code.

## Description

In this task, you install or open the Foundry Toolkit extension in Visual Studio Code, connect it to your active Foundry project, and test the `zava-shopping-agent` directly from the extension interface.

## Success Criteria

- The Foundry Toolkit extension is available in Visual Studio Code.
- Your active Foundry project is set as the default project.
- You can see `zava-shopping-agent` under **Prompt Agents**.
- The agent responds to a test prompt in Visual Studio Code.

## Key Tasks

### 01: Install and open the Foundry Toolkit extension

If you already installed the extension, you can move directly to the next step.

1. Open Visual Studio Code.

1. Select **Extensions** from the left pane, or press **Ctrl+Shift+X**.

1. Search for the `Foundry Toolkit for VS Code` extension from Microsoft.

1. Select **Install**.

    Installing this extension adds the Foundry Toolkit experience to Visual Studio Code.

    > **Note**: The extension is currently listed as **Foundry Toolkit**, but some labels, commands, or screenshots may still refer to **AI Toolkit**. In this exercise, treat those names as referring to the same extension experience.

1. After the extension is installed, select the Foundry Toolkit icon in the sidebar.

1. Sign in to your Azure account if prompted.

### 02: Set the default project and open the agent

You now connect the extension to the Foundry project you created so you can work with the same resources from Visual Studio Code.

1. Under **Microsoft Foundry Resources**, choose **Set Default Project**.

1. If a default project is already active, note that the project name appears in the resources list. If needed, select the same **Select project** icon to choose a different project.

1. Expand the project section.

1. Under **Prompt Agents**, locate `zava-shopping-agent`.

1. Select the agent name to open the Agent Builder interface.

    The agent playground appears in Visual Studio Code, which lets you test and update the agent without leaving your development environment.

### 03: Test the agent in the extension

Before writing code, quickly validate that the agent responds correctly in the extension interface.

1. In the playground chat pane, enter the following prompt:

    ```text
    What is the policy for reporting a lost or stolen device?
    ```

1. Review the response.

    The response should use the uploaded grounding data and confirm that the agent is available from Visual Studio Code.

1. Keep Visual Studio Code open for the next task.

    > **Tip**: This built-in playground is a fast way to validate prompts, tools, and instructions before you automate agent interactions in code.
