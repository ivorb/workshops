# Task 01 - Create the Zava shopping agent in Microsoft Foundry

## Introduction

Zava now needs more than image understanding alone. To support store associates and online shoppers, the assistant must answer grounded retail questions and work with structured data so it can help with product discovery, compatibility, and assisted selling scenarios.

## Description

In this task, you open Microsoft Foundry, create an agent for Zava's shopping assistant, and configure it with retail instructions, grounding content, and built-in tools. You also upload sample files the agent can use for file search and code interpreter scenarios.

## Success Criteria

- You create a new Microsoft Foundry project and agent.
- The agent uses Zava-specific retail instructions.
- The agent has both **File search** and **</> Code interpreter** enabled.
- The grounding and analysis files are uploaded and ready.

## Key Tasks

### 01: Create a Foundry project and agent

Microsoft Foundry uses projects to organize models, resources, data, and other assets used to develop an AI solution.

1. Open Microsoft Edge and go to the Foundry portal at `https://ai.azure.com`.

1. Sign in by using your Azure credentials.

1. Close any tips or quick start panes that open the first time you sign in.

1. If needed, use the **Foundry** logo at the upper left to return to the home page.

    > **Important**: For this exercise, you're using the **New** Foundry experience.

1. In the top banner, select **Start building** to try the new Microsoft Foundry experience.

1. When prompted, create a **new** project, and enter a valid project name such as `zava-shopping-agent-project`.

1. Expand **Advanced options** and specify the following settings:
    - **Microsoft Foundry resource**: `ai-zava-foundry`
    - **Region**: *Select one available near you*
    - **Subscription**: *Your Azure subscription*
    - **Resource group**: `rg-zava-workshop`

    > **Note**: Some Azure AI resources are constrained by regional model quotas. If you later encounter a quota limit, you may need to create another resource in a different region.

1. Select **Create** and wait for the project to be created.

1. When the project opens, read through the welcome dialog if it appears, and then select **Create agent**.

    You can also select **Start building** on the home page and then select **Create agents** from the drop-down menu.

1. Set the **Agent name** to `zava-shopping-agent` and create the agent.

The playground opens for the newly created agent. An available deployed model should already be selected for you.

### 02: Add retail instructions and grounding data

Now that the agent exists, you can tailor it for Zava's omnichannel retail scenario.

1. In the agent playground, set the **Instructions** to the following prompt:

    ```prompt
    You are a shopping assistant for Zava, a DIY home improvement retailer.
    You help customers and store associates identify products, answer shopping questions, and support assisted commerce scenarios.

    Guidelines:
    - Always be professional, helpful, and concise
    - Use the provided retail reference content to answer questions accurately
    - If you don't know the answer, say so and suggest a safe next step
    - When helping with shopping tasks, gather the necessary details before making recommendations
    ```

    This instruction set positions the agent for Maya Patel's omnichannel MVP and Sofia Ramirez's store-associate use cases.

1. Open a new browser tab and download the retail reference document from:

    ```text
    https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-agents/main/Labfiles/01-build-agent-portal-and-vscode/IT_Policy.txt
    ```

1. Save the file to your local machine.

    > **Note**: The sample file name remains `IT_Policy.txt`, but in this workshop you use it as stand-in retail grounding content for the Zava shopping assistant. Keep the file name unchanged so the exercise steps continue to work correctly.

1. Return to the agent playground.

1. In the **Tools** section, select **Add**, and then add both **File search** and **</> Code interpreter**.

1. To the right of **Add**, select **Upload files**.

1. Under **Attach files**, browse to and upload the `IT_Policy.txt` file, and then select **Attach**.

1. Wait for the file to be indexed.

    You should see a confirmation when the file is ready for the agent to use.

1. Open a new browser tab and download the sample data file from:

    ```text
    https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-agents/main/Labfiles/01-build-agent-portal-and-vscode/system_performance.csv
    ```

1. Save the file to your local machine.

    > **Note**: The sample file name remains `system_performance.csv`. In this workshop, you use it as stand-in retail analysis data so you can validate the agent's code interpreter workflow without changing the underlying technical implementation.

1. Return to the agent playground.

1. To the right of **</> Code interpreter**, select **+ Files**.

1. Upload the `system_performance.csv` file.

1. Select **Save** to save the agent configuration.

### 03: Verify the shopping agent in the portal

Before you move into development, verify that the agent can answer grounded questions and analyze uploaded data.

1. In the chat pane on the right side of the playground, enter the following prompt:

    ```text
    What's the policy for password resets?
    ```

1. Review the response.

    Even though the content is sample workshop data, the response should be grounded in the uploaded file and should demonstrate that file search is working.

1. Enter the following prompt:

    ```text
    How do I request new software?
    ```

1. Review the response and confirm that the agent again uses the uploaded grounding file.

1. Enter the following prompt to test code interpreter:

    ```text
    Can you analyze the system performance data and tell me if there are any concerning trends?
    ```

1. Review the response and confirm that the agent analyzes the CSV data.

1. Enter the following prompt to request a visualization:

    ```text
    Create a chart showing CPU usage over time from the performance data
    ```

1. Review the response and confirm that the agent uses code interpreter to generate analysis or a chart.

At this point, you have a Zava-themed shopping agent with grounding data, file search, and code interpreter configured in Microsoft Foundry.
