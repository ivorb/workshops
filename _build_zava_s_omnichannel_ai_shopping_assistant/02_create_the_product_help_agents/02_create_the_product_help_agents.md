# Exercise 02: Create the Product Help Agents

## Scenario



## Objectives

After you complete this exercise, you will be able to:

* Create a Zava product help agent in the Foundry portal by using the shared workshop environment.
* Configure the agent with instructions, grounding data, file search, and code interpreter.
* Test the agent in the Foundry portal and in Visual Studio Code.
* Build a Python client application that connects to the agent programmatically.
* Verify that the agent can answer grounded questions, analyze uploaded data, and generate output files.

## Duration

* **Estimated Time:** 45 minutes
