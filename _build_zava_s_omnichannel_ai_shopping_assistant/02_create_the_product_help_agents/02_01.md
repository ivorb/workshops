# Task 01 - Create and configure the Zava product help agent

## Introduction

In this task, you create the product help agent that supports the next stage of Zava Assist. This matters because Zava needs a grounded assistant that can answer product and support-style questions consistently across digital and in-store channels, while staying aligned with approved information.

## Description

You open the shared workshop project in the Foundry portal, create a new agent, and configure it with instructions, grounding data, file search, and code interpreter. You use the shared workshop naming convention so the solution stays consistent with the rest of the build.

## Success Criteria

- You open the shared Foundry project in the Foundry portal.
- You create an agent named `zava-product-help-agent`.
- You add instructions that frame the agent for Zava's retail scenario.
- You upload the grounding files and enable **File search** and **</> Code interpreter**.
- You save the agent successfully.

## Key Tasks

### 01: Open the shared workshop project

1. Open the [Foundry portal](https://ai.azure.com) at `https://ai.azure.com` and sign in using your Azure credentials. Close any tips or quick start panes that open the first time you sign in, and if necessary use the **Foundry** logo at the top left to navigate to the home page.

    > **Important**: For this exercise, you're using the **New** Foundry experience.

1. In the top banner, select **Start building** to use the new Microsoft Foundry experience.

1. Open the shared workshop project that you created in the previous exercise by selecting the project associated with the shared workshop resource `ai-zava-foundry`.

1. When the project opens, verify that you're working in the shared Zava workshop environment rather than creating a new project.

### 02: Create the Zava product help agent

1. In the project, select **Create agent**.

    You can also select **Start building** on the home page, and select **Create agents** from the drop-down menu.

1. Set the **Agent name** to `zava-product-help-agent` and create the agent.

1. Wait for the playground to open for your newly created agent.

    You should see that an available deployed model is already selected for you from the shared workshop setup.

### 03: Add instructions and grounding data

1. In the agent playground, set the **Instructions** to the following text:

    ```prompt
    You are a Product Help Agent for Zava, a retail DIY chain.
    You help shoppers and store associates with product questions and retail policy-style guidance.

    Guidelines:
    - Always be professional and helpful
    - Use the uploaded documentation to answer questions accurately
    - If you don't know the answer, admit it and suggest contacting a human colleague directly
    - When helping with follow-up cases, collect all necessary information before proceeding
    ```

    This instruction set keeps the original technical behavior of the exercise while aligning the agent to the Zava retail scenario.

1. Open a new browser tab and navigate to the following URL:

    ```text
    https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-agents/main/Labfiles/01-build-agent-portal-and-vscode/IT_Policy.txt
    ```

1. Save the file to your local machine.

    > **Note**: This document contains the sample grounding content used in the exercise. In the workshop story, treat it as approved Zava help content that the product help agent can reference.

1. Return to the agent playground. In the **Tools** section, select **Add**, and then add both **File search** and **</> Code interpreter**.

1. To the right of **Add**, select **Upload files**. Under **Attach files**, browse to and upload the `IT_Policy.txt` file you just downloaded, and then select **Attach**.

1. Wait for the file to be indexed.

    You should see a confirmation when the file is ready to use.

1. Open a new browser tab and navigate to the following URL:

    ```text
    https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-agents/main/Labfiles/01-build-agent-portal-and-vscode/system_performance.csv
    ```

1. Save the file to your local machine.

    > **Note**: This CSV file contains the sample data used by the exercise for code interpreter analysis. In the workshop story, treat it as operational support data that Zava uses for richer agent-assisted analysis.

1. Return to the agent playground. To the right of **</> Code interpreter**, select **+ Files**, and then upload the `system_performance.csv` file you just downloaded.

1. Save the agent.

1. Verify that the agent now includes the uploaded files and the enabled tools.

    You should see **File search** and **</> Code interpreter** listed for the agent, along with the attached files.
