# Task 04 - Connect Visual Studio Code to the Foundry project

## Introduction

Zava's developers do not work only in the browser. They also need an efficient way to explore and use project resources from Visual Studio Code as they build the shopping assistant. In this task, you install the Foundry Toolkit extension and connect it to the shared workshop project.

## Description

In this task, you install **Foundry Toolkit for VS Code**, sign in to Azure from Visual Studio Code, set `ai-zava-foundry` as the default project, and open the deployed model in the VS Code playground.

## Success Criteria

- You install the **Foundry Toolkit for VS Code** extension.
- You connect the extension to Azure and set `ai-zava-foundry` as the default project.
- You can browse the deployed `gpt-5.2` model in Visual Studio Code.
- You can open the model playground in Visual Studio Code.

## Key Tasks

### 01: Install the Foundry Toolkit extension

The Foundry Toolkit extension provides a convenient way to work with Foundry project resources without leaving the development environment.

1. Start Visual Studio Code.

1. Select the **Extensions** view in the navigation bar on the left.

1. Search the extensions marketplace for `Foundry Toolkit`.

1. Install the **Foundry Toolkit for VS Code** extension.

The extension may take a minute or so to install.

1. After the extension is installed, select the **Foundry Toolkit** page in the left navigation bar and wait for it to load.

![Screenshot of the Foundry Toolkit Visual Studio Code extension.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-studio/main/Instructions/media/foundry-vs-extension.png)

1. Verify that the Foundry Toolkit pane opens successfully.

### 02: Connect to Azure and set the default project

This connection lets you browse the shared workshop resources directly from Visual Studio Code.

1. In the Foundry Toolkit pane, expand **Microsoft Foundry Resources**.

1. Connect to Azure by signing in with your credentials.

1. Set the default project to the Foundry project you created previously, `ai-zava-foundry`.

1. Wait for the project tree to load.

### 03: Review the deployed model

Viewing the model from Visual Studio Code confirms that your local development environment is connected to the same shared project you configured in the portal.

1. Expand the `ai-zava-foundry` project.

1. Expand **Models**.

1. Select the `gpt-5.2` model that you deployed previously.

1. Review the model deployment details.

![Screenshot of a model in the  Foundry Toolkit Visual Studio Code extension.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-studio/main/Instructions/media/vscode-extension-model.png)

You should now see the deployed model details in the Foundry Toolkit interface.

### 04: Open the model playground in Visual Studio Code

The VS Code playground gives you a developer-friendly way to test models while staying in the same environment where you will later write code.

1. In the Foundry Toolkit pane, in the **Developer Tools** section, expand **Build**.

1. Select **Model playground**.

1. Select the `gpt-5.2` model if it is not already selected.

1. Review the interactive playground that opens in Visual Studio Code.

![Screenshot of the model playground in Visual Studio Code.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-studio/main/Instructions/media/vscode-model-playground.png)

1. Verify that the playground loads and that the selected model is `gpt-5.2`.

At this point, Zava's developer workspace is ready in both the Foundry portal and Visual Studio Code, which prepares you for the next exercise in the workshop.
