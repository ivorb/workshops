# Task 01 - Create Zava's shared Foundry project

## Introduction

Before Zava can build an omnichannel AI shopping assistant, the team needs a shared AI development workspace. This task creates the Microsoft Foundry project that organizes models, resources, and connections for the rest of the workshop.

## Description

In this task, you sign in to Microsoft Foundry portal and create the project environment that Zava's developer team will use. You use the workshop resource group and the exact shared resource name defined for the solution.

## Success Criteria

- You create a Foundry project named `ai-zava-foundry`.
- The project uses the resource group `rg-zava-workshop`.
- You can open the Foundry project home page successfully.

## Key Tasks

### 01: Open Microsoft Foundry portal and sign in

Microsoft Foundry uses projects to organize models, resources, data, and other assets used to develop an AI solution.

1. Open a web browser and go to the [Microsoft Foundry portal](https://ai.azure.com) at `https://ai.azure.com`.

1. Sign in by using your Azure credentials.

1. Close any tips or quick start panes that appear the first time you sign in.

### 02: Create the shared Zava project

This project becomes the central workspace for Zava's AI shopping assistant. Later exercises in the workshop build on the resources and connections created here.

1. Enable the **New Foundry** option in the toolbar at the top of the page if it is not already enabled.

1. Create a new project and expand **Advanced options**.

1. Enter or select the following settings for the project:
   - **Project name**: `ai-zava-foundry`
   - **Foundry resource**: `ai-zava-foundry`
   - **Subscription**: *Your Azure subscription*
   - **Resource group**: `rg-zava-workshop`
   - **Region**: Select any of the **AI Foundry recommended** regions in **[this list](https://learn.microsoft.com/azure/foundry/openai/how-to/responses#region-availability)**

   > **Tip**: Make a note of the region you selected. You'll need it later in the workshop.

1. Select **Create**.

1. Wait for the project to be created.

1. Review the project home page when it opens.

![Screenshot of the Foundry project home page.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-studio/main/Instructions/media/foundry-portal-home.png)

You should now see the home page for `ai-zava-foundry`, which confirms that the shared workshop project is ready.

### 03: Verify the project foundation

At this point, you have created the shared workspace that supports Zava's implementation work across the workshop.

1. Confirm that the project home page displays the `ai-zava-foundry` project.

1. Confirm that the project is associated with the `rg-zava-workshop` resource group.

1. Keep the browser tab open for the next task.

This completes the shared project setup that Liam Chen and the rest of Zava's development team will use.
