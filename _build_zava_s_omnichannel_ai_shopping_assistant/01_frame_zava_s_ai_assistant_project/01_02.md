# Task 02 - Deploy and test the retail assistant model

## Introduction

At the core of Zava's shopping assistant is a generative AI model that can interpret shopper questions and support guided product discovery. In this task, you deploy a model and test it in the playground so you can confirm that the project is ready for later retail scenarios.

## Description

In this task, you open the model catalog, locate the `gpt-5.2` model, deploy it with default settings, and test it with a prompt framed around AI development planning. This validates that the project can host and use a model successfully.

## Success Criteria

- You locate the `gpt-5.2` model in the Foundry model catalog.
- You deploy the model successfully.
- You test the model in the playground and receive a response.

## Key Tasks

### 01: Open the model catalog

The model catalog helps you discover available models and review their capabilities before deployment.

1. On the **Discover** page, select the **Models** tab.

1. Review the Microsoft Foundry model catalog.

### 02: Review the gpt-5.2 model card

Model cards provide information that helps you understand model capabilities, limitations, and suitability for a solution like Zava's retail assistant.

1. Search for the `gpt-5.2` model.

1. Select the model in the search results to open its model card.

![Screenshot of the gpt-5.2 model card.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-studio/main/Instructions/media/gpt5.2-details.png)

1. Review the model information to understand whether it is appropriate for Zava's AI shopping assistant scenarios.

### 03: Deploy the model

A deployment makes the model available for testing and for use by applications in the project.

1. Select **Deploy**.

1. Use the default settings to create the deployment.

1. Wait for the deployment to finish.

1. Review the model playground when it opens automatically.

![Screenshot of the Foundry project model playground.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-studio/main/Instructions/media/ai-foundry-model-playground.png)

You should now see the deployed `gpt-5.2` model in the playground.

### 04: Test the deployed model

A quick test confirms that the model is available and responding correctly before you use it in later exercises.

1. In the **Instructions** box, enter the following text:

    ```text
    You are an AI assistant that can provide information and advice about AI software development.
    ```

   This instruction sets the assistant behavior for the playground test.

1. In the chat window, enter the following query:

    ```text
    Describe three key considerations for working with Large Language Models for AI application development.
    ```

1. Review the response from the model.

Hopefully the model provides some useful considerations that you can carry into the rest of the workshop.

1. Verify that the chat completes successfully and that the model returns a coherent answer.

This confirms that `ai-zava-foundry` is ready to support Zava's next implementation steps.
