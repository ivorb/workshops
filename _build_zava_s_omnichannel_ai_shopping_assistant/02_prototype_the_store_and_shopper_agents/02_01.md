# Task 01 - Create and configure the Zava Assist agent

## Introduction

This task establishes the first working agent experience for Zava Assist. You use the shared project from exercise 01 to create a retail-focused agent that can support shoppers and store associates with grounded answers and lightweight data analysis.

## Description

In this task, you open the existing project in the Foundry portal, create an agent for Zava Assist, add retail-specific instructions, and attach files that the agent can use through **File search** and **</> Code interpreter**.

## Success Criteria

- You open the existing `aiproj-zava-assist` project in the Foundry portal.
- You create an agent named `zava-assist-agent`.
- You add instructions that align the agent to Zava's retail support scenario.
- You attach a text file for grounding and a CSV file for data analysis.
- You save the configured agent successfully.

## Key Tasks

### 01: Open the shared Zava Assist project in the Foundry portal

You already created the shared Foundry environment in exercise 01. Now you return to that environment so you can add an agent to the existing project.

1. Open Microsoft Edge and go to the Foundry portal at `https://ai.azure.com`.

1. Sign in with your Azure credentials.

1. Close any tips or quick-start panes if they appear.

1. If necessary, use the **Foundry** logo at the top left to return to the home page.

    > **Important**: For this exercise, you're using the **New** Foundry experience.

1. In the top banner, select **Start building** to use the new Microsoft Foundry experience.

1. Open the existing project named `aiproj-zava-assist`.

    You created this project in exercise 01 inside the `rg-zava-workshop` resource group.

1. In the project, start creating a new agent. If a welcome dialog appears, select **Next** through the welcome content and then select **Create agent**.

    You can also select **Start building** and choose **Create agents**.

1. Set the **Agent name** to `zava-assist-agent`, and create the agent.

1. Verify that the agent playground opens and that an available deployed model is already selected.

### 02: Add retail instructions and grounding data

The Zava Assist agent needs instructions that reflect Zava's omnichannel retail use case. You also attach files so the agent can answer grounded questions and analyze uploaded data.

1. In the agent playground, set the **Instructions** to the following prompt:

    ```prompt
    You are Zava Assist, an AI shopping assistant for Zava, a retail DIY chain.
    You help shoppers and store associates with product questions, merchandising support questions, and retail guidance.

    Guidelines:
    - Always be professional and helpful
    - Use the attached retail policy and product guidance documentation to answer questions accurately
    - If you don't know the answer, admit it and suggest involving a human colleague
    - When a request involves complaints, returns disputes, safety concerns, or customer frustration, recommend escalation to a human support lead or store manager
    ```

    This instruction keeps the technical behavior the same as the original lab while aligning the narrative to Zava Assist.

1. Open a new browser tab and download the grounding document from:

    ```text
    https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-agents/main/Labfiles/01-build-agent-portal-and-vscode/IT_Policy.txt
    ```

1. Save the file to your local machine.

    Although the file name remains `IT_Policy.txt`, you use it in this workshop as a stand-in for Zava retail policy and product guidance content.

1. Return to the agent playground.

1. In the **Tools** section, select **Add**, and add both **File search** and **</> Code interpreter**.

1. To the right of **Add**, select **Upload files**.

1. Under **Attach files**, browse to and upload the `IT_Policy.txt` file that you downloaded, and then select **Attach**.

1. Wait for the file to finish indexing.

1. Open a new browser tab and download the CSV file from:

    ```text
    https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-agents/main/Labfiles/01-build-agent-portal-and-vscode/system_performance.csv
    ```

1. Save the file to your local machine.

    Although the file name remains `system_performance.csv`, you use it in this workshop as sample store operations data that the agent can analyze.

1. Return to the agent playground.

1. To the right of **</> Code interpreter**, select **+ Files**, and upload the `system_performance.csv` file.

1. Save the agent.

1. Verify that the agent now shows both **File search** and **</> Code interpreter**, and that the uploaded files are attached.

### 03: Validate the agent in the Foundry portal

Before you move into Visual Studio Code, verify that the Zava Assist agent responds correctly in the portal. This gives you confidence that the instructions, files, and tools are working as expected.

1. In the chat pane on the right side of the playground, enter the following prompt:

    ```text
    What's the policy for password resets?
    ```

1. Review the response.

    In this workshop narrative, treat this as a grounded policy-style support question that a store associate or internal team member might ask. The agent should use the attached document to answer accurately.

1. Enter the following prompt:

    ```text
    How do I request new software?
    ```

1. Review the response and confirm that the agent continues to use the attached grounding file.

1. Enter the following prompt:

    ```text
    Can you analyze the system performance data and tell me if there are any concerning trends?
    ```

1. Review the response and confirm that the agent uses **</> Code interpreter** to analyze the CSV file.

1. Enter the following prompt:

    ```text
    Create a chart showing CPU usage over time from the performance data
    ```

1. Review the response and confirm that the agent can generate a visualization from the uploaded data.

1. Verify that the agent can answer grounded questions and perform data analysis in the same playground session.
