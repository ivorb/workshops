# Task 04 - Run and validate the Zava Assist application

## Introduction

This task confirms that the end-to-end developer workflow works for Zava Assist. You run the Python client application, connect to the shared Foundry project, and verify that the agent can answer grounded questions and analyze CSV data from the terminal.

## Description

In this task, you start the client app, test several prompts, review the saved outputs, and then clean up the resources that were created for the exercise.

## Success Criteria

- The Python application starts and connects to `zava-assist-agent`.
- The app answers grounded questions successfully.
- The app performs CSV analysis and can generate charts.
- Generated files are saved to the `agent_outputs` folder.
- You delete the project or resource group when you finish.

## Key Tasks

### 01: Run and test the client application

You now run the app and verify that the Zava Assist agent works programmatically, not just in the portal or extension UI.

1. In the Visual Studio Code terminal, run the application:

    ```bash
    python agent_with_functions.py
    ```

1. Verify that the application connects to the Foundry project, loads `zava-assist-agent`, and displays the interactive prompt.

1. At the running prompt, test grounded question answering by entering:

    ```input
    What's the policy for password resets?
    ```

1. Review the response.

    In this workshop, treat this as a stand-in for a grounded support or associate guidance question. The answer should use the attached text file.

1. Test CSV analysis by entering:

    ```input
    Analyze the system performance data and identify any periods where CPU usage exceeded 80%
    ```

1. Review the response and confirm that the agent analyzes the uploaded CSV file.

1. Test chart generation by entering:

    ```input
    Create a line chart showing memory usage trends over time
    ```

1. Review the output and confirm that the app reports a saved chart path in the `agent_outputs` folder.

1. Test statistical analysis by entering:

    ```input
    What are the average, minimum, and maximum values for disk usage in the performance data?
    ```

1. Review the answer and confirm that the agent returns computed results.

1. Test combined analysis by entering:

    ```input
    Find any correlation between high CPU usage and memory usage in the performance data
    ```

1. Review the response.

1. When you finish testing, type:

    ```input
    exit
    ```

1. In File Explorer inside Visual Studio Code, review the `agent_outputs` folder and confirm that generated files are saved there when applicable.

1. In the terminal, deactivate the Python environment:

    ```bash
    deactivate
    ```

    > **Tip**: If the app fails because the rate limit is exceeded, wait a few seconds and try again.

### 02: Clean up the workshop resources for this exercise

If you're continuing directly to exercise 03, you may choose to keep the shared environment in place. If you've finished exploring, remove the resources to avoid unnecessary Azure costs.

1. In the Foundry portal, open the `aiproj-zava-assist` project.

1. Select **Settings** > **Delete project**.

1. Confirm the deletion if you no longer need the project for the workshop.

1. Alternatively, open the Azure portal and view the contents of the `rg-zava-workshop` resource group.

1. On the toolbar, select **Delete resource group**.

1. Enter `rg-zava-workshop`, and confirm the deletion.

1. Verify that the resources are scheduled for deletion.
