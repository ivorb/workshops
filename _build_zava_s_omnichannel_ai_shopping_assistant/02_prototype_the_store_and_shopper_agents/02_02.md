# Task 02 - Test the agent in Visual Studio Code

## Introduction

Developers often move between the Foundry portal and Visual Studio Code while building solutions. This task helps you confirm that the same Zava Assist agent is available through the Foundry Toolkit extension so you can continue development in your normal coding environment.

## Description

In this task, you install or open the Foundry Toolkit extension, connect to the existing `aiproj-zava-assist` project, and test the `zava-assist-agent` directly inside Visual Studio Code.

## Success Criteria

- You open Visual Studio Code and access the Foundry Toolkit extension.
- You set `aiproj-zava-assist` as the default project if needed.
- You locate `zava-assist-agent` under **Prompt Agents**.
- You test the agent successfully in the Agent Builder interface.

## Key Tasks

### 01: Install and open the Foundry Toolkit extension

The Foundry Toolkit extension lets you work with project resources without leaving Visual Studio Code.

1. Open Visual Studio Code.

1. Select **Extensions** in the left pane, or press **Ctrl+Shift+X**.

1. Search for the `Foundry Toolkit for VS Code` extension from Microsoft.

1. If it isn't already installed, select **Install**.

    > **Note**: The extension is currently listed as **Foundry Toolkit**, but some labels, commands, or older screenshots may still refer to **AI Toolkit**. In this exercise, treat those names as referring to the same extension experience.

1. After the extension is installed, select the Foundry Toolkit icon in the activity bar.

1. If prompted, sign in to your Azure account.

1. Verify that the extension opens successfully and shows **Microsoft Foundry Resources**.

### 02: Open the Zava Assist agent in VS Code

Now connect the extension to the same project that you created earlier so you can reuse the portal-created agent.

1. Under **Microsoft Foundry Resources**, choose **Set Default Project**.

1. If a default project is already active, review the displayed project name. If needed, select the same project selector to choose `aiproj-zava-assist`.

1. Expand the active project.

1. Under **Prompt Agents**, locate `zava-assist-agent`.

1. Select `zava-assist-agent` to open the Agent Builder interface.

1. In the playground chat pane, enter the following prompt:

    ```text
    What is the policy for reporting a lost or stolen device?
    ```

1. Review the response.

    In this workshop, treat this as another grounded internal support scenario that Zava teams may route through the same assistant platform. The response should come from the file you attached earlier.

1. Verify that the agent is available in Visual Studio Code and can respond successfully without recreating any resources.
