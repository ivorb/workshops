# Task 01 - Validate the vision model in Foundry

## Introduction

Before you build the app experience for Zava Assist, you first confirm that the shared workshop environment can handle multimodal prompts. This gives you confidence that the same model foundation used for agent workflows can also interpret product imagery for online shoppers and store associates.

## Description

In this task, you open the Foundry portal, confirm that the shared workshop project is available, deploy a vision-capable model if needed, and test it with an image prompt in the chat playground.

## Success Criteria

- You sign in to the Foundry portal and open the shared workshop project.
- You confirm access to the Azure OpenAI endpoint for `aoai-zava-assistant`.
- You deploy or verify a `gpt-5.2` model deployment.
- You successfully submit an image-based prompt in the playground and review the response.

## Key Tasks

### 01: Open the shared workshop project

To keep the workshop continuous, you continue working in Zava's shared Azure AI environment rather than creating a new project. This keeps your app aligned with the same resources used in the previous exercise.

1. Open Microsoft Edge, and then open the Microsoft Foundry portal at `https://ai.azure.com`.

1. Sign in using your Azure credentials.

1. Close any tips or quick start panes that open automatically.

1. Open the existing workshop project that uses the shared Azure AI environment for Zava. Use the project connected to `ai-zava-foundry` in the resource group `rg-zava-workshop`.

1. On the project home page, review the connection details and note the Azure OpenAI endpoint that you will use later for the client application.

    > **Tip**: You need the Azure OpenAI endpoint for `aoai-zava-assistant` later when you configure the app.

### 02: Deploy a multimodal model

You need a model that can accept both text and image input. In this workshop, you use the same model capability to support shelf and product-photo scenarios for Zava Assist.

1. In the Foundry portal, navigate to the **Discover** page.

1. Select the **Models** tab to view the Microsoft Foundry model catalog.

1. Search for the `gpt-5.2` model.

1. Deploy the `gpt-5.2` model by using the default settings.

    > **Tip**: Model deployments are subject to regional quotas. If you don't have enough quota to deploy the model in your project's region, you can use a different model - such as gpt-5.2-mini, or gpt-4o. Alternatively, you can create a new project in a different region.

1. Wait for the deployment to finish, and then open the model playground page for the deployment.

1. Note the model deployment name. By default, it should be `gpt-5.2`.

### 03: Test image input in the chat playground

Before you write code, you verify the vision scenario directly in the portal. This helps you isolate model behavior from application code and confirm the deployment is ready.

1. In a new browser tab, download `mango.jpeg` from `https://microsoftlearning.github.io/mslearn-ai-vision/Labfiles/gen-ai-vision/mango.jpeg` and save it to a local folder.

1. Return to the chat playground page for your deployed model in the Foundry portal.

1. In the main chat session panel, under the chat input box, use the attach button (**📎**) to upload the `mango.jpeg` image file.

1. Enter the text `What desserts could I make with this fruit?`, and then submit the prompt.

![Screenshot of the chat playground page.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-vision/main/Instructions/media/chat-playground-image-new.png)

1. Review the response.

1. Verify that the model identifies the image content and suggests relevant dessert ideas.

    > **Note**: In the Zava workshop, this same multimodal capability enables Zava Assist to interpret product and shelf imagery so associates and shoppers can get guidance based on what they are looking at.
