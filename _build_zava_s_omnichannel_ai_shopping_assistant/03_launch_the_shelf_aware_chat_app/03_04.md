# Task 04 - Clean up the workshop resources

## Introduction

When you finish testing, you should remove any Azure resources you no longer need. This helps Zava avoid unnecessary costs in shared workshop subscriptions.

## Description

In this task, you delete the resource group that contains the workshop resources.

## Success Criteria

- You locate the workshop resource group in the Azure portal.
- You delete `rg-zava-workshop`.
- You confirm that the cleanup operation starts successfully.

## Key Tasks

### 01: Delete the resource group

If you have finished exploring the Azure AI resources used in this workshop, clean up the deployment to avoid ongoing charges.

1. Open the Azure portal at `https://portal.azure.com`.

1. View the contents of the `rg-zava-workshop` resource group.

1. On the toolbar, select **Delete resource group**.

1. Enter `rg-zava-workshop`, and then confirm that you want to delete it.
