# Task 03 - Build and test the multimodal chat flow

## Introduction

With the workspace ready, you now implement the multimodal chat behavior that turns Zava Assist into a shelf-aware shopping experience. You first connect the app to the model by using Entra ID authentication, then test a remote image prompt, and finally switch to a local image upload scenario.

## Description

In this task, you update the Python app to create an OpenAI client, submit a prompt with an image URL, sign in to Azure and run the app, and then modify the code to upload a local image file for a second test.

## Success Criteria

- You add the required SDK imports and create an authenticated OpenAI client.
- You run the app successfully after signing in with Azure CLI.
- You receive a response based on a remote image URL.
- You update the app to send a local image file and receive a second multimodal response.

## Key Tasks

### 01: Add the OpenAI client code

To keep authentication aligned with workshop best practices, you use Entra ID instead of API keys. This lets the app securely access the model deployment in Zava's Azure environment.

1. In Visual Studio Code, open the `image-chat-app.py` file.

1. Review the existing statements at the top of the file that import the necessary SDK namespaces.

1. Find the comment `Add references`, and then add the following code:

    ```python
    # Add references
    from openai import OpenAI
    from azure.identity import DefaultAzureCredential, get_bearer_token_provider
    ```

    This code imports the OpenAI client and the Azure identity classes required for token-based authentication.

1. In the `main` function, review the code under the comment `Get configuration settings` and note that it loads the endpoint and model deployment values from the `.env` file.

1. Find the comment `Create an OpenAI client`, and then add the following code:

    ```python
    # Create an OpenAI client
    credential = DefaultAzureCredential()
    token_provider = get_bearer_token_provider(credential, "https://ai.azure.com/.default")
    client = OpenAI(
        base_url=openai_endpoint,
        api_key=token_provider()
    )
    ```

    This code creates an authenticated client that connects to your Azure OpenAI deployment through the configured endpoint.

1. Save the file by using **Ctrl+S**.

### 02: Submit a prompt with a remote image URL

You first test the app with a hosted image. This is a quick way to confirm that the client, authentication flow, and multimodal request format all work correctly.

1. In the code loop that accepts user prompts, find the comment `Get a response to image input`.

1. Add the following code under that comment:

![A photo of an orange.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-vision/main/Instructions/media/orange.jpeg)

    ```python
    # Get a response to image input
    image_url = "https://microsoftlearning.github.io/mslearn-ai-vision/Labfiles/gen-ai-vision/orange.jpeg"
    response = client.responses.create(
         model=model_deployment,
         input=[
             {"role": "developer", "content": system_message},
             { "role": "user", "content": [
                 { "type": "input_text", "text": prompt},
                 { "type": "input_image", "image_url": image_url}
             ]}
         ]
    )
    print(response.output_text)
    ```

    This code sends the learner's prompt together with a remote image URL so the model can reason over both text and image input.

1. Save the file by using **Ctrl+S**.

### 03: Sign in and run the app

Before the app can use `DefaultAzureCredential`, you need to authenticate to Azure in the local development environment. After that, you run the app and verify the first multimodal response.

1. In the integrated terminal, run the following command to sign in to Azure:

    ```powershell
    az login
    ```

    > **Note**: In most scenarios, just using `az login` will be sufficient. However, if you have subscriptions in multiple tenants, you may need to specify the tenant by using the `--tenant` parameter. See `https://learn.microsoft.com/cli/azure/authenticate-azure-cli-interactively` for details.

1. When prompted, follow the instructions to sign in to Azure.

1. Complete the sign-in process in the command line, and then review the subscription details to confirm that you are connected to the subscription containing `ai-zava-foundry` and `aoai-zava-assistant`.

1. Run the application with the following command:

    ```text
    python image-chat-app.py
    ```

1. When prompted, enter the following text:

    ```input
    Suggest some recipes that include this fruit
    ```

1. Review the response that the model returns.

1. Verify that the app successfully uses the image and prompt together to generate a relevant answer.

1. Enter `quit` to exit the program.

    > **Tip**: If the app fails because the rate limit is exceeded, wait a few seconds and try again.

### 04: Modify the app to upload a local image file

A local file upload is closer to the Zava Assist scenario, where a shopper or associate may provide a photo taken in the moment. You now update the app to send image data from a local file instead of a hosted URL.

1. In the code editor, find the code you added previously under the comment `Get a response to image input`.

1. Replace that code with the following code to upload the local `mystery-fruit.jpeg` file:

![A photo of a dragon fruit.](https://raw.githubusercontent.com/MicrosoftLearning/mslearn-ai-vision/main/Instructions/media/mystery-fruit.jpeg)

    ```python
    # Get a response to image input
    image_path = Path("mystery-fruit.jpeg")
    image_format = "jpeg"
    with open(image_path, "rb") as image_file:
         image_data = base64.b64encode(image_file.read()).decode("utf-8")

    data_url = f"data:image/{image_format};base64,{image_data}"

    response = client.responses.create(
         model=model_deployment,
         input=[
             {"role": "developer", "content": system_message},
             { "role": "user", "content": [
                 { "type": "input_text", "text": prompt},
                 { "type": "input_image", "image_url": data_url}
             ]}
         ]
    )
    print(response.output_text)
    ```

    This code reads a local image file, converts it to a base64-encoded data URL, and includes that image in the model request.

1. Save the file by using **Ctrl+S**.

1. In the integrated terminal, run the app again:

    ```text
    python image-chat-app.py
    ```

1. When prompted, enter the following text:

    ```input
    What is this fruit? What recipes could I use it in?
    ```

1. Review the response.

1. Verify that the model identifies the fruit and suggests appropriate recipe ideas based on the uploaded image.

1. Enter `quit` to exit the program.

1. Deactivate the Python environment by running the following command:

    ```bash
    deactivate
    ```

    > **Note**: In this simple app, you haven't implemented logic to retain conversation history; so the model treats each prompt as a new request with no context of the previous prompt.
