# Task 02 - Prepare the shelf-aware chat application

## Introduction

Now that you have verified the model in the playground, you can prepare the developer workspace for the app that Priya Nair will extend into Zava Assist. The goal is to connect the application to the shared workshop resources while keeping the implementation simple and testable.

## Description

In this task, you clone the sample repository, open the Python app files, configure the app to use the Azure OpenAI endpoint from `aoai-zava-assistant`, and install the required dependencies.

## Success Criteria

- You clone the repository and open the correct project folder in Visual Studio Code.
- You create or select a Python 3.13 virtual environment.
- You update the `.env` file with the correct Azure OpenAI endpoint and model deployment name.
- You install the required Python packages successfully.

## Key Tasks

### 01: Clone the application files

You start from the provided starter files so you can focus on connecting the app to Zava's Azure environment and adding multimodal functionality.

1. Open Visual Studio Code.

1. Open the **Command Palette** with **Ctrl+Shift+P**.

1. Run the `Git:clone` command.

1. Clone the repository from `https://github.com/microsoftlearning/mslearn-ai-vision` to a local folder of your choice.

1. Open the cloned repository in Visual Studio Code.

1. If prompted, confirm that you trust the authors.

1. In the **Extensions** pane, verify that the **Python** extension is installed. If it isn't installed, install it.

1. Open the **Command Palette** again, run the `Python: Select Interpreter` command, and then select an existing environment or create a new **Venv** environment based on Python 3.13.x.

    > **Tip**: If you are prompted to install dependencies, you can install the ones in the `requirements.txt` file in the `/labfiles/gen-ai-vision/python` folder; but it's OK if you don't - you'll install them later.

### 02: Review the starter files

Before changing configuration, review the files that make up the sample app so you know where settings and code belong.

1. Open the folder in Visual Studio Code by using **File** > **Open Folder**.

1. Navigate to the `/labfiles/gen-ai-vision/python` folder.

1. In the **Explorer** pane, review the files in the folder:

    - `.env` - A configuration file for application settings.
    - `image-chat-app.py` - The Python code file for the image application.
    - `requirements.txt` - A file listing the package dependencies.
    - `mystery-fruit.jpeg` - An image of a fruit.

### 03: Configure the app for Zava's Azure resources

The app must use the Azure OpenAI endpoint from the shared workshop environment. This ensures the shelf-aware chat experience runs against the same deployment you validated in Foundry.

1. In the **Explorer** pane, open the `.env` file.

1. Update the configuration values to include the Azure OpenAI endpoint for `aoai-zava-assistant` and the deployment name for the model you deployed in the previous task.

    > **Important**: Be sure to add the `https://{foundry-resource-name}.openai.azure.com/openai/v1/` Azure OpenAI endpoint, not the project endpoint.

1. Save the modified configuration file by using **Ctrl+S**.

### 04: Install the required dependencies

With configuration in place, you can install the Python packages the app needs to authenticate and call the model.

1. In the **Explorer** pane, right-click the **python** folder that contains the application files, and then select **Open in Integrated Terminal**.

    > **Note**: Opening the terminal in Visual Studio Code will automatically activate the Python environment. You may need to enable running scripts on your system.

1. Verify that the terminal is open in the `/labfiles/gen-ai-vision/python` folder and that the prefix **(.venv)** appears.

1. Run the following command to install the required Python packages:

    ```text
    pip install -r requirements.txt
    ```

1. Wait for the installation to finish.

1. Verify that the command completes without errors before continuing.
