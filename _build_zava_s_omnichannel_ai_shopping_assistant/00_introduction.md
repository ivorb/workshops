# Build Zava's omnichannel AI shopping assistant

**Difficulty** ▰▰▰▱▱ **L300**

In this workshop, you'll plan and build key foundations of an AI-powered retail assistant for Zava, a DIY home improvement chain. You'll start by defining the AI project, success criteria, and responsible AI considerations, then create a vision-enabled chat experience that can understand product and part images from customers, and finally extend the solution with AI agents in Azure AI Foundry and VS Code that can reason over retail tasks and take actions such as helping customers find products, answering shopping questions, and supporting assisted commerce scenarios.

Zava is a fictional omnichannel DIY retail chain with e-commerce, mobile, and physical stores. Its customers often begin projects online, then visit stores with photos of broken fittings, paint samples, appliance parts, or handwritten shopping lists. Zava wants a single AI shopping assistant that can help customers and store associates identify products from images, answer questions about suitability and alternatives, and eventually act on a shopper's behalf across digital and in-store journeys. The company needs a practical path from project planning to a working prototype that aligns with retail priorities such as product discovery, catalog accuracy, customer engagement, and operational efficiency.

In this workshop, you are part of Zava's developer team delivering the first iteration of that assistant. You will begin by preparing the AI development effort around a clear retail use case, stakeholders, data and risk considerations, and measurable outcomes. Next, you will build a vision-enabled chat app that can combine natural language and images so shoppers can ask, "What replacement part is this?" or "Which sealant should I use with this pipe fitting?" Finally, you will add AI agents that can orchestrate richer retail workflows, laying the groundwork for an assistant that not only understands customer intent but can also support guided shopping and action-oriented experiences for Zava's omnichannel business.

## Prerequisites

For running this workshop you will need:

* An Azure subscription with permission to create resource groups and Azure AI resources.
* Access to Azure AI Foundry and Azure OpenAI in the selected region.
* A development environment with Visual Studio Code installed.
* Git and a modern web browser.
* Basic familiarity with Python or JavaScript application development.
* Basic understanding of REST APIs, JSON, and Azure resource management.
