# Task 02 - Prepare the Zava vision chat application

## Introduction

Now that you have confirmed the model can process images in the Foundry portal, you build a local developer prototype for Ethan Brooks. This app gives Zava a repeatable way to test vision-enabled retail assistance outside the playground.

## Description

You clone the sample repository, open the Python app files, configure the application to use Zava's Azure OpenAI endpoint and model deployment, and install the required dependencies.

## Success Criteria

- You clone the repository and open the correct Python folder in Visual Studio Code.
- You review the app files, including `.env`, `image-chat-app.py`, `requirements.txt`, and `mystery-fruit.jpeg`.
- You update `.env` with the Azure OpenAI endpoint and deployment name from `aiproj-zava-assist`.
- You create or select a Python 3.13 virtual environment and install dependencies successfully.

## Key Tasks

### 01: Clone the sample files and open them in Visual Studio Code

The initial application files are provided in a GitHub repository so you can focus on implementing the vision features.

1. Open Visual Studio Code.

1. Open the command palette with **Ctrl+Shift+P** and run the `Git: Clone` command.

1. Clone the `https://github.com/microsoftlearning/mslearn-ai-vision` repository to a local folder.

1. Open the cloned repository in Visual Studio Code.

1. If prompted, confirm that you trust the authors.

1. In Visual Studio Code, open the **Extensions** pane and install the **Python** extension if it is not already installed.

1. Open the **Command Palette**, run the `Python: Select Interpreter` command, and then select an existing environment or create a new **Venv** environment based on your Python 3.13.x installation.

    > **Tip**: If you are prompted to install dependencies, you can install the ones in the `requirements.txt` file in the `/labfiles/gen-ai-vision/python` folder, but you install them explicitly in a later step.

### 02: Configure the application settings

You now point the sample app at Zava's existing Azure OpenAI deployment.

1. Open the folder in VS Code by selecting **File** > **Open Folder** and navigate to `/labfiles/gen-ai-vision/python`.

1. In the **Explorer** pane, review the files in the folder:

    - `.env` - A configuration file for application settings.
    - `image-chat-app.py` - The Python code file for the image application.
    - `requirements.txt` - A file listing the package dependencies.
    - `mystery-fruit.jpeg` - An image of a fruit.

1. In the **Explorer** pane, open the `.env` file.

1. Update the configuration values to include the **Azure OpenAI endpoint** for Zava's Foundry resource and the model deployment name for the generative AI model you deployed in `aiproj-zava-assist`.

    > **Important**: Be sure to add the `https://{foundry-resource-name}.openai.azure.com/openai/v1/` Azure OpenAI endpoint, not the project endpoint.

1. Save the `.env` file by pressing **Ctrl+S**.

1. Verify that the endpoint value points to the Azure OpenAI resource associated with Zava's environment, such as `aoai-zava-workshop`.

### 03: Install the Python dependencies

With the configuration in place, you prepare the local environment to run the application.

1. In the **Explorer** pane, right-click the `python` folder containing the application files and select **Open in Integrated Terminal**.

    > **Note**: Opening the terminal in Visual Studio Code automatically activates the Python environment in most cases. You may need to enable running scripts on your system.

1. Verify that the terminal is open in the `/labfiles/gen-ai-vision/python` folder and that the prompt includes `(.venv)`.

1. Run the following command to install the required packages:

    ```bash
    pip install -r requirements.txt
    ```

    This command installs the Python dependencies required for the image-enabled chat app.

1. Wait for package installation to complete.

1. Verify that the installation finishes without errors.

    You should be ready to edit and run `image-chat-app.py`.
