# Task 04 - Update Zava Assist to analyze a local shelf image

## Introduction

Store associates like Sofia Ramirez may capture photos directly from a mobile device instead of referencing a public image URL. In this task, you update the prototype so Zava Assist can upload and analyze a local image file, which is a practical pattern for in-store shelf and product support.

## Description

You modify the existing image-input logic to send a local file as base64-encoded image data, test the application again, and then clean up the workshop resources when you are finished.

## Success Criteria

- You replace the URL-based image logic with local file upload logic.
- You run the app and receive a useful response about the local image.
- You understand that the sample does not retain conversation history.
- You deactivate the Python environment when testing is complete.
- You delete workshop resources to avoid unnecessary Azure charges.

## Key Tasks

### 01: Modify the app to upload a local image file

You now switch from a web-hosted image to a local file so the app can analyze an image captured on a device.

1. In the code editor for `image-chat-app.py`, locate the code you added under the comment `Get a response to image input`.

1. Replace that code with the following:

    ```python
    # Get a response to image input
    image_path = Path("mystery-fruit.jpeg")
    image_format = "jpeg"
    with open(image_path, "rb") as image_file:
         image_data = base64.b64encode(image_file.read()).decode("utf-8")

    data_url = f"data:image/{image_format};base64,{image_data}"

    response = client.responses.create(
         model=model_deployment,
         input=[
             {"role": "developer", "content": system_message},
             { "role": "user", "content": [  
                 { "type": "input_text", "text": prompt},
                 { "type": "input_image", "image_url": data_url}
             ]} 
         ]
    )
    print(response.output_text)
    ```

    This code reads the local image file, converts it to base64, creates a data URL, and sends it to the model as image input.

1. Save the file by pressing **Ctrl+S**.

1. Verify that the file `mystery-fruit.jpeg` exists in the same folder as `image-chat-app.py`.

### 02: Run the app with the local image

You now test the updated app by asking the model to identify and suggest uses for the local image.

1. In the terminal, run the application again:

    ```bash
    python image-chat-app.py
    ```

1. When prompted, enter the following text:

    ```input
    What is this fruit? What recipes could I use it in?
    ```

1. Review the response.

    You should receive a useful answer that identifies the fruit and suggests recipe ideas based on the uploaded local image.

1. Enter `quit` to close the app.

1. Review the app behavior and note that this simple sample does not retain conversation history, so each prompt is treated as a new request.

1. When you have finished testing, deactivate the Python environment by running:

    ```bash
    deactivate
    ```

### 03: Clean up the Zava workshop resources

If you have finished exploring the Azure AI services used in this workshop, you should delete the resources you created to avoid incurring unnecessary Azure costs.

1. Open the Azure portal at `https://portal.azure.com`.

1. View the contents of the `rg-zava-workshop` resource group.

1. On the toolbar, select **Delete resource group**.

1. Enter `rg-zava-workshop` and confirm that you want to delete it.

1. Verify that deletion starts for the Zava workshop resources, which can include `aihub-zava-workshop`, `aiproj-zava-assist`, `aoai-zava-workshop`, `aisvc-zava-workshop`, `stzavaworkshop`, `appi-zava-assist`, and `aca-zava-assist`.
