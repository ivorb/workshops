# Task 01 - Validate Zava's vision model in Azure AI Foundry

## Introduction

Zava Assist already supports grounded retail conversations through the agent you created in `aiproj-zava-assist`. In this task, you verify that the shared Zava environment can also process image input so associates and shoppers can ask richer questions about products and shelf conditions.

## Description

You open the Foundry portal, make sure you are working in Zava's existing project, confirm that a vision-capable model deployment is available, and test it in the playground with an uploaded image.

## Success Criteria

- You open the Foundry portal and work in `aiproj-zava-assist`.
- You confirm that a vision-capable deployment such as `gpt-5.2` is available.
- You submit an image prompt in the playground and receive a relevant response.
- You note the Azure OpenAI endpoint and deployment name for later use in the app.

## Key Tasks

### 01: Open the Zava Foundry project

You use the shared Zava project from the workshop so this exercise continues directly from the agent work you completed earlier.

1. Open the Microsoft Foundry portal at `https://ai.azure.com` and sign in with your Azure credentials.

1. Close any tips or quick-start panes if they appear.

1. If it is not already enabled, on the toolbar at the top of the page, enable the **New Foundry** option.

1. Open the existing project named `aiproj-zava-assist`.

1. Verify that the project is associated with Zava's workshop environment, including resources such as `rg-zava-workshop`, `aihub-zava-workshop`, `aoai-zava-workshop`, and `aisvc-zava-workshop`.

1. On the project home page, review the connection details that are displayed and note the **Azure OpenAI endpoint**.

    > **Important**: You use the Azure OpenAI endpoint later in the Python app. Be sure to note the Azure OpenAI endpoint, not the project endpoint.

### 02: Confirm a vision-capable model deployment

You need a model that can accept image input for Zava's shelf-aware chat experience.

1. On the **Discover** page, select the **Models** tab to view the Microsoft Foundry model catalog.

1. Search for the `gpt-5.2` model and deploy it by using the default settings if it is not already deployed in `aiproj-zava-assist`.

    > **Tip**: Model deployments are subject to regional quotas. If you do not have enough quota to deploy the model in your project's region, you can use a different model such as `gpt-5.2-mini` or `gpt-4o`. Alternatively, you can create a new project in a different region, but for this workshop continue to use `aiproj-zava-assist` whenever possible.

1. Wait for deployment to finish.

1. When the deployment opens in the model playground, note the deployment name. By default, it should be `gpt-5.2`.

1. Verify that the playground is ready to accept prompts.

### 03: Test image input in the playground

Before you write code, you verify that the model can reason over image input in the portal experience.

1. In a new browser tab, download `mango.jpeg` from `https://microsoftlearning.github.io/mslearn-ai-vision/Labfiles/gen-ai-vision/mango.jpeg` and save it to a local folder.

1. Return to the chat playground for your deployment in the Foundry portal.

1. In the main chat session panel, under the chat input box, use the attach button (**📎**) to upload the `mango.jpeg` image file.

1. Enter the following prompt and submit it:

    ```text
    What desserts could I make with this fruit?
    ```

1. Review the response.

1. Verify that the response identifies useful dessert ideas based on the uploaded image.

    You should see a relevant answer that uses the fruit shown in the image as the basis for recipe suggestions.
