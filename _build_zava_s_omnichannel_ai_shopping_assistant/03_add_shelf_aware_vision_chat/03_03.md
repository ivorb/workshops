# Task 03 - Build and run Zava's URL-based vision chat

## Introduction

In this task, you connect the local app to Zava's deployed model by using the OpenAI SDK and Microsoft Entra ID authentication. You then send a text-and-image request by referencing an image URL, which is a useful pattern for online retail scenarios where product images are already available on the web.

## Description

You update `image-chat-app.py` to import the required libraries, create an authenticated OpenAI client, submit a URL-based image prompt, sign in to Azure, and test the app from the terminal.

## Success Criteria

- You add the required OpenAI and Azure Identity imports.
- You create an authenticated `OpenAI` client by using `DefaultAzureCredential`.
- You submit a prompt that includes an image URL and receive a response.
- You sign in with `az login` before running the app.
- You verify that the app responds to a retail image prompt successfully.

## Key Tasks

### 01: Add the SDK references

You first add the namespaces the app needs for the OpenAI client and Entra ID authentication.

1. In VS Code, open the `image-chat-app.py` file.

1. Find the comment `Add references` and add the following code:

    ```python
    # Add references
    from openai import OpenAI
    from azure.identity import DefaultAzureCredential, get_bearer_token_provider
    ```

    This code imports the OpenAI client and the Azure Identity helpers used to obtain a bearer token.

1. Save the file by pressing **Ctrl+S**.

### 02: Create an authenticated OpenAI client

The application uses the configuration from `.env` together with your signed-in Azure identity.

1. In the `main` function, under the comment `Get configuration settings`, review the existing code that loads the endpoint and model deployment values from the configuration file.

1. Find the comment `Create an OpenAI client` and add the following code:

    ```python
    # Create an OpenAI client
    credential = DefaultAzureCredential()
    token_provider = get_bearer_token_provider(credential, "https://ai.azure.com/.default")
    client = OpenAI(
        base_url=openai_endpoint,
        api_key=token_provider()
    )
    ```

    This code creates a token-based client connection to the Azure OpenAI endpoint in Zava's environment.

1. Save the file by pressing **Ctrl+S**.

    > **Tip**: As you add code, be sure to maintain the correct indentation. Use the existing comments as a guide, entering the new code at the same level of indentation.

### 03: Submit a URL-based image prompt

You now add the logic that sends both text and image input in a single request.

1. In the loop section of `image-chat-app.py`, find the comment `Get a response to image input`.

1. Add the following code under that comment:

    ```python
    # Get a response to image input
    image_url = "https://microsoftlearning.github.io/mslearn-ai-vision/Labfiles/gen-ai-vision/orange.jpeg"
    response = client.responses.create(
         model=model_deployment,
         input=[
             {"role": "developer", "content": system_message},
             { "role": "user", "content": [  
                 { "type": "input_text", "text": prompt},
                 { "type": "input_image", "image_url": image_url}
             ]} 
         ]
    )
    print(response.output_text)
    ```

    This code sends the user's prompt together with an image URL so the model can reason over both inputs.

1. Save the file by pressing **Ctrl+S**.

1. Review the code and verify that it references `model_deployment` and `openai_endpoint` values that match the configuration for `aiproj-zava-assist`.

### 04: Sign in and run the application

Before the app can authenticate by using `DefaultAzureCredential`, you need to sign in to Azure.

1. In the terminal pane, run the following command:

    ```powershell
    az login
    ```

    This command signs you in to Azure so the SDK can obtain a token for the OpenAI client.

1. When prompted, follow the instructions to sign in.

1. Complete the sign-in process in the command line and confirm that you are using the subscription that contains Zava's resources, including `rg-zava-workshop`.

    > **Note**: In most scenarios, just using `az login` is sufficient. However, if you have subscriptions in multiple tenants, you may need to specify the tenant by using the `--tenant` parameter.

1. Run the application:

    ```bash
    python image-chat-app.py
    ```

1. When prompted, enter the following text:

    ```input
    Suggest some recipes that include this fruit
    ```

1. Review the response.

    You should receive a relevant answer based on the image URL and your prompt.

1. Enter `quit` to exit the program.

1. If the app fails because the rate limit is exceeded, wait a few seconds and try again.
